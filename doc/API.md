# 通达信上游 API 调用速查

按仓库实际请求实现及协议证据整理。这里的 API 指**最终发往通达信服务器的 HTTP 请求、TCP 命令和文件资源**。输出列说明上游数据内容；TCP 二进制、ZIP/DAT 和 PBRPC 均需解码，不能直接当 JSON 使用。

可直接使用单文件工具 [tdx_api.py](../tdx_api.py)，仅需 Python 3.10+ 标准库：

```bash
python tdx_api.py --help-all
python tdx_api.py quote sz000001
python tdx_api.py cloud --entry CWSearch.tzx_rcache --body '{"action":"get","key":"gg:0_000001","bin":"1","qsid":"tdx"}'
python tdx_api.py jsn themes
python tdx_api.py download tdxfin/gpcw.txt
```

`catalog` 列出接口和模板来源；`cloud --config <XML或安装目录> --req-id <请求号>` 读取实际模板。
所有请求支持 `--dry-run`；`raw` 可发送本文其他 TCP 命令，但只解帧/解压，业务体按 hex 或二进制输出。
行情、K线和成交查询按单页返回；PBRPC 自动拼接传输分片，ZIP/DAT 只下载原文件。

## 1. 实际请求地址

| 通道 | 地址 | 请求 / 响应 |
|---|---|---|
| 普通行情、JSN 文件 | `connect.cfg` 中 `HQHOST` 行情节点，通常 TCP `7709` | 通达信二进制帧；按命令号区分功能 |
| 港股、期货等扩展行情 | 扩展行情节点 TCP `7727`；代码内候选如 `116.205.143.214:7727` | 扩展市场二进制帧 |
| TQLEX / PBRPC 云查询 | `http://static.tdx.com.cn:7615/TQLEX?Entry=<服务名>` | HTTP POST；JSON 或 protobuf 请求体 |
| 股东跨股票持仓 | `http://page1.tdx.com.cn:7615/TQLEX?Entry=CWServ.tdxf10_gg_gdyjcgmx` | HTTP POST JSON |
| 专业财务、交易数据文件 | `https://data.tdx.com.cn/` | HTTP GET；清单文本、ZIP 或 DAT |

地址来自现有实现与客户端配置。行情节点可切换；本文不把某个 IP 视为永久固定地址。

## 2. TCP 7709：普通行情

输入为二进制业务字段。市场号通常为 `0=深圳、1=上海、2=北京`，证券代码为 6 位 ASCII（如 `000001`）；日期通常为整数 `YYYYMMDD`，多字节整数按小端序编码。

| 命令号 | 用途 | 输入 | 输出 |
|---|---|---|---|
| `0x000D` | 建立普通行情会话 | 固定握手数据 `01` | 会话响应、服务器信息 |
| `0x0004` | 心跳、取得服务端时间信息 | 空业务体 | 心跳及时间数据 |
| `0x044E` | 查询证券数量 | 市场号、客户端日期 | 该市场证券总数 |
| `0x044D` | 分页读取证券目录 | 市场号、起始位置、数量 | 代码、名称、价格小数位、昨收等，每条 37 字节 |
| `0x054C` | 批量最新行情 | 证券数量、市场号与代码列表 | 最新价、昨收、开高低、成交量额、内外盘等 |
| `0x053E` | 批量涨速及五档 | 证券数量、市场号与代码列表 | 行情核心、服务端涨速、买卖五档 |
| `0x0547` | 五档及增量行情 | 证券列表、每票增量状态字段 | 行情与买卖五档；响应另有 XOR 解码 |
| `0x054B` | 服务端行情排序 | 分类、排序字段、起始位置、数量、方向、过滤位 | 排序后的证券行情列表 |
| `0x052D` | 多周期 K 线 | 市场、代码、周期号、周期参数、起始位置、数量 | 时间、开高低收、成交量额 |
| `0x0FC5` | 当日成交明细 | 市场、代码、起始位置、数量 | 时间、价格、成交量、买卖方向 |
| `0x0FC6` | 历史成交明细 | 日期、市场、代码、起始位置、数量 | 指定交易日成交明细 |
| `0x056A` | 开盘、收盘集合竞价 | 市场、代码、`selector`、起始位置、数量 | 虚拟成交价、匹配量、买卖未匹配量；`selector=0` 只取开盘 |
| `0x0010` | 批量基础财务 | 证券数量、市场号与代码列表 | 股本、EPS、资产负债、收入利润、股东人数、报告日期等，每条 143 字节 |
| `0x000F` | 股本变迁、除权除息 | 市场、代码 | 日期、事件类别、分红送转及股本变化 |
| `0x0452` | 特殊品种涨跌停限制 | 起始位置 | 证券及限制数据，每条 13 字节 |
| `0x02C5`（709） | 查询远端文件信息 | NUL 补齐的 40 字节路径，如 `bi/list/func_gx_hyzt101_1.jsn` | 文件长度、MD5 标记和 MD5 |
| `0x06B9`（1721） | 分块下载远端文件 | 偏移、请求字节数、文件路径；JSN 每块最多 30000 字节 | `uint32 返回长度 + 文件字节`；用于 JSN，也用于 `zhb.zip` |

K 线周期号：`7=1分钟、0=5分钟、1=15分钟、2=30分钟、3=60分钟、4=日、5=周、6=月`；当前 K 线实现每页最多 800 条。前后复权由取得的 K 线与 `0x000F` 事件本地计算。

封包格式为 `前缀 + message_id + 控制字节 + 两份长度 + 命令号 + 业务体`；普通行情前缀 `0x0C`，先握手再发送业务请求，响应按长度解帧并按需 zlib 解压。逐字段实现见 [传输层](../native/src/market/transport.cpp)、[行情请求](../native/src/market/market_protocol.cpp)、[K 线请求](../native/src/market/minute_download.cpp)。

## 3. TCP 7727：港股、期货等扩展行情

市场号和合约代码从目录返回值取得，例如港股市场 `31`；代码最长 9 字节，不能一律套用 A 股的 6 位代码规则。请求前缀为 `0x01`。

| 命令号 | 用途 | 输入 | 输出 |
|---|---|---|---|
| `0x2454` | 建立扩展行情会话 | 固定扩展握手体 | 握手响应 |
| `0x23F0` | 合约总数 | 空业务体 | 扩展市场合约总数 |
| `0x23F5` | 分页合约目录 | 起始位置、数量 | 市场、代码、名称、价格精度、合约乘数等 |
| `0x23FA` | 最新报价 | 市场、合约代码 | 最新价、开高低、量、持仓、盘口等 |
| `0x23FF` | 扩展市场 K 线 | 市场、代码、周期、起始位置、数量 | OHLC、成交量、持仓及品种附加字段 |
| `0x240B` | 当日分时 | 市场、代码 | 分钟价格、成交量序列 |
| `0x240C` | 历史分时 | 日期、市场、代码 | 指定日分时序列 |
| `0x23FC` | 当日逐笔 | 市场、代码、起始位置、数量 | 时间、价格、成交量、持仓变化、方向标记 |
| `0x2406` | 历史逐笔 | 日期、市场、代码、起始位置、数量 | 指定日逐笔及持仓变化 |

期权目录筛选、到期日解析、IV、Greeks 由这些行情和本地规则计算，没有单独的同名上游 HTTP 接口。[请求实现](../native/src/market/minute_download_expansion.cpp)

## 7. TCP 7709 文件接口：常用业务资源

JSN 通过 `709 → 1721` 读取，统计包 `zhb.zip` 直接用 `1721` 分块下载；这些路径**不是 HTTP URL**。表中 JSN 路径省略统一前缀 `bi/`；固定主表通常下载后在本地筛选，动态路径的 ID 从主表取得。

## 8. HTTP GET：专业财务与交易文件

地址统一加前缀 `https://data.tdx.com.cn/`。按文件整体下载，再按证券、日期或字段在本地筛选。

| 路径 | 用途 | 输入 | 原始输出 |
|---|---|---|---|
| `tdxfin/gpcw.txt` | 财务包目录 | 无 | 文件名、MD5、长度清单 |
| `tdxfin/gpcw<YYYYMMDD>.zip` | 指定报告期专业财务 | 清单内的报告期 | ZIP，内含同名 DAT；包含多证券财务字段 |
| `tdxgp/gpszsh.txt` | 专业交易数据目录 | 无 | 交易数据文件清单、MD5、长度 |
| `tdxgp/gp<市场><代码>.dat` | 个股或板块专业交易序列 | 清单文件名，如 `gpsz000001.dat` | 按日期排列的字段编号及数值，13 字节记录 |
| `tdxgp/gpsh999999.dat` | 全市场专业交易序列 | 固定路径 | 两融、资金、涨跌家数等市场数据 |

财务包日期是报告期，不等于实际披露日；实际披露日另从公告/披露资源取得。[下载实现](../native/src/protocol/professional_data_fetch.cpp)

当前实现中的 MACD 等公式求值、组合回测、TPool、Level2 离线构造/解码属于本地计算；它们没有对应的同名通达信上游 API。
