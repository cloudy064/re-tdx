# 通达信逆向工程 · 攻坚任务列表

> 2026-07-30，Phase 0 完成后。任务按 Phase 编排，每项有明确输入、输出和验收标准。
> 约定：每个具体任务 \(P_n\) 对应一个编号，前一个 Phase 完成后再推进到下一个 Phase。

## 总体策略

1. **先侦察后分析**：Phase 1 摸清运行时全貌（进程树、网络拓扑、自保护、脚本接口），避免直接深入 IDA 却错过关键入口。
2. **先导出表后反编译**：优先用 `dumpbin /exports` + FLOSS 快速扫描 DLL 的导出函数和混淆字符串；对最有价值的 DLL 再投入 IDA 深度分析。
3. **先主进程后插件**：TdxW.exe 是核心宿主，先按真实加载点和调用图
   区分 `TdxAsioComm`、`tpbus/TaApi`、数据插件与认证插件，不按 DLL
   文件名假设串行顺序。
4. **协议分析需双轨并行**：网络抓包（Wireshark/tdx-l2-sniffer）+ IDA 静态分析同时推进，互相验证。
