# 原生 C++ 国债逆回购链路模块化

日期：2026-08-11

## 目标

拆解 630 行的 `reverse_repo.cpp`。原文件混合三种 view、11 项排序、四项等价日历资源、
JSN 日历、公开 L1 行情、利息/费用计算、摘要、双缓存、行情失败降级、筛选、响应和 CLI。

## 落地结果

原根文件已移除，并拆为九个实现单元：类型目录、公共转换、日历/行情归一化、排序、摘要、
查询计划、双缓存抓取、服务编排和 CLI。`ViewSpec` 管理三种 view 及单票约束；`SortSpec`
将 11 个公开排序名直接绑定到字段与数值/文本类型，view、sort 均有编译期唯一性检查。
四项等价资源集中到目录输出，主资源只有一个定义入口。

行情仍是可选附加源：JSN 结算日历先独立获取，公开 `0x054C` 快照失败只写入 warning 并降级
为 `schedule-only`，不会隐藏期限、计息天数、费用及资金可用/可取日期。毛收益、费用、净收益
和净年化公式、回购价格两位小数语义均保持不变。
