# 主动基金季度持仓纯 C++ 迁移

## 目标

把“主动基金增持”从已验证的 JSN 主从链迁入统一工具，并在输出中明确区分
基金季报披露、股票汇总和逐基金详情，避免把季度数据误解为实时完整持仓。

## 页面、键与单位

- `ZDJJZCZC.sp` 的主组件使用 `func_zdjjzczc101.cfg`，详情组件使用
  `func_zdjjzczc102.cfg`；
- 主表为 `list/func_zdjjzczc101_1.jsn`，股票键是 `$SC+$ZQDM`；
- 详情 CFG 声明 `file="zdjjzczc"`，因此路径为
  `zdjjzczc/<市场号><六位股票代码>.jsn`；
- `zdjjzczc/1601666.jsn` 是正例，省略市场号或添加错误市场号均不存在；
- 主表市值为元、数量为股；详情 `cgsz/cgsl/zjzb/cgwl` 分别是元、股、
  百分比原值和重仓排名，不做万/亿的隐式缩放。

客户端标题说明该表由基金公开季度报告统计，并非基金所有持股。本次将该
边界同时写入 API 字段命名、独立页面和个股侧栏。

## 原生实现

新增命令：

```powershell
tdx-tool market active-funds --root C:\new_tdx --view securities `
  --direction increased

tdx-tool market active-funds --root C:\new_tdx --view funds `
  --market sh --code 601666
```

固定 API 是 `/api/v1/market/active-funds`，只接受 `securities/funds` 两种
视图，不允许调用者传任意资源路径。主表缓存 5 分钟，动态详情及不存在结果
缓存 15 分钟。独立 Svelte 页面支持搜索和增持/新进/减持筛选；点击股票后
展开持有基金。个股“更多”新增“主动基金”，仅在打开页签时请求，不增加
个股首屏负担。
