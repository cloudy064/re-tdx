# 原生 C++ 板块基础链路模块化

日期：2026-08-11

原 868 行 `blocks.cpp` 同时承担固定板块/市场目录、TNF 与行业树解析、主营业务与证券缓存、
自定义/组合板块文件、InfoHarbor 综合装载、JSON/CSV 和 CLI。现拆分如下：

| 文件 | 职责 | 行数 |
|---|---|---:|
| `blocks_internal.hpp` | 5 个板块族、3 个市场的编译期类型目录与内部端口 | 54 |
| `blocks_support.cpp` | 目录查找、文本/整数/定长字段和证券回退支持 | 100 |
| `blocks_parse.cpp` | 314/360 字节 TNF、行业层级、行业归属解析 | 142 |
| `blocks_business.cpp` | 主营业务、评分、用户行业模式和两类失效缓存 | 192 |
| `blocks_custom.cpp` | 自定义板块、组合板块目录与成员文件 | 174 |
| `blocks_loader.cpp` | InfoHarbor 解析、五类板块筛选、综合装载与排序 | 145 |
| `blocks_command.cpp` | JSON/CSV 投影、查询与导出 CLI | 287 |

旧根文件已移除。公开 `blocks.hpp`、板块层级、成员归属、命令参数和 JSON/CSV 字段保持不变。
原先散落在映射中的五类板块与三类市场改为编译期类型目录，解析器、缓存和命令入口不再互相
持有私有实现。

为避免以后改板块底层还要运行整套公式解释器测试，新增 171 行的 `tdx-blocks-tests`，直接
覆盖 TNF、行业父子层级、祖先/直接归属、InfoHarbor、主营业务首记录规则、用户行业模式、
自定义板块和组合板块。该专项测试与 `tdx-tool` 构建、执行通过。平安银行真实查询返回 34 个
板块归属，覆盖五个板块族，34 条证券名称全部解析成功。本轮未运行完整 CTest。
