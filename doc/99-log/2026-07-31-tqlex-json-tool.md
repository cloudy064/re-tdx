# TQLEX 普通 JSON 配置发现与分页工具

> 日期：2026-07-31  
> 范围：`T0002/cloud_cfg` 中启用的 `reqformat=2` 配置与
> `static.tdx.com.cn:7615/TQLEX`

## 配置面

排除 XML 注释后，当前安装有：

- 73 条 `reqformat=2` datasource；
- 11 个唯一 Entry；
- 34 个唯一数字 ReqId；
- 71 条数组请求模板和 2 条对象模板。

56 条模板使用类似 Python 字面量的单引号，17 条使用标准 JSON 双引号。
7 条使用客户端分页宏：

```text
$$$STARTPOS$ $$
$$$PAGEROWS$ $$
```

旧版扫描器会把三美元分页宏的一部分误识别为普通 `$$NAME$$` 参数；
占位符正则已增加边界，并在解析请求前单独替换分页宏。

## 实现

新增 `doc/90-scripts/tdx_tqlex.py`：

- 按 ReqId、Entry、XML 文件和请求体包含文本选择启用配置；
- 优先解析标准 JSON，兼容客户端单引号字面量；
- 支持 `--set` 替换模板参数、`--param` 覆盖请求字段；
- 支持显式 JSON 请求；
- 自动处理 `Page/PageSize` 与 `page/pageSize`，保留模板键名大小写；
- `--all-pages` 按页请求，直至主结果集不足一页；
- 只合并分页主结果集，不重复追加每页相同的总数/元数据结果集；
- 检测重复页、列变化、结果集数量变化和服务端 `error/ErrorCode`；
- 使用原子写入保存 UTF-8 JSON，不修改通达信安装目录。

普通 JSON POST 仍使用：

```text
POST http://static.tdx.com.cn:7615/TQLEX?Entry=<datasource name>
Content-Type: application/json
```

## 分页语义

实测 `Page` 是页号而不是记录偏移。基金接口以 `PageSize=3` 请求时，
`Page=0/1/3` 分别返回第 1—3、4—6、10—12 条。

不同服务页长上限不同：

- 基金筛选 `500050` 接受 `PageSize=100`；
- 异常波动 `2044` 接受 50，但 100 返回
  `{"error":"Invalid Page Size"}`。

因此工具默认使用保守的 20 行；明确知道接口上限时可通过
`--page-size` 提高。

## 真实验证

### 基金主表与持仓

`500050` 使用以下条件：

```text
style_details=005001
fund_size=0
fund_setup_time=0
report_date=20250630
PageSize=100
```

工具请求 12 页并合并出 1,187 只普通股票型基金，字段包括净值、涨跌、
换手率、持股数量、股票/行业集中度、持仓市值、基金公司、规模、成立日和
经理。

以主表中的基金 `000326` 继续请求：

| ReqId | 功能 | 行数 |
| --- | --- | ---: |
| `500051` | 行业持仓 | 11 |
| `500052` | 股票持仓 | 106 |

股票持仓包含代码、名称、现价、涨跌、持股数量、市值和占比。季度末可能
没有明细；`20250630/20241231` 等半年报、年报日期可返回。

### 异常波动

`2044` 使用小写 `page/pageSize`。以 50 行请求 18 页后：

- 主结果集：877 条；
- 汇总结果集：一行 `total_num=877`。

工具只合并主结果集，汇总结果不会被复制 18 次。

### 单引号与重复模板

`200661` 配置使用单引号，并有 `flag=1/2` 两个相同 ReqId 模板。通过：

```text
--body-contains "'flag':'2'"
```

成功选择 T+0 机会模板，本次返回 37 条。
