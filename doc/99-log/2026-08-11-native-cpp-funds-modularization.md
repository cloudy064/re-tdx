# 原生 C++ 分时主力资金链路模块化

日期：2026-08-11

## 目标

拆解 624 行的 `funds.cpp`。原文件混合七个时段字段映射、研究行业拓扑、`200340` 主表、
`200341` 明细、四种查询模式、记录归一化、双缓存重试、全行业反向索引、响应和 CLI。

## 落地结果

原根文件已移除，并拆为九个实现单元：时段/来源目录、公共 PBRPC 转换、记录归一化、行业
拓扑、主/明细抓取、主表/行业投影、单票/全行业投影、模式分派和 CLI。七个 `PeriodSpec`
统一绑定公开 key、中文名、上游字段后缀和时长，key 与 suffix 均有编译期唯一性检查。

原有 `Fetcher` 注入端口保持不变，主表和动态行业明细继续独立缓存；两类请求均保留三次
瞬态重试和陈旧缓存回退。主表、单行业、单票、全行业反向索引四种模式各自位于明确的投影
边界，不再集中在一个查询函数内。
