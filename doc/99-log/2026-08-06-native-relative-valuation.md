# 指数相对估值纯 C++ 固定化

`zs_zsgzb.xml` 定义了一条普通 JSON 主表 `200000` 和一条 PBRPC 从表
`200001`。这里的“估值比”不是已有 `market valuation` 的指数自身 PE/PB
百分位，而是目标指数估值指标除以所选基准指数的同口径指标。客户端支持
PE(TTM)、PB(MRQ)、PS(TTM)，宽基、行业、综合、主题、规模五类指数，以及
上证指数、沪深300、上证50、中证500、创业板指五个基准。

新增纯 C++ `market relative-valuation` 与固定
`/api/v1/market/relative-valuation`。不传 `code` 时返回当前参数下的指数概览；
传入六位指数代码后，先从主表验证选择，再用 `200001` 展开每日估值比历史。
主表与各指数明细分开缓存，切换指数不会重复下载主表；瞬时 HTTP、业务码 4
或 `RpcID=-1` 失败会有限重试，并可回退同参数陈旧缓存。接口不接受任意 URL。

默认参数在 2026-08-06 实测返回 180 个指数。`SH000026 180资源` 相对
上证指数的 PE(TTM) 历史从 2024-08-06 到 2026-08-05，共 484 点；最新
估值比 0.886，区间最小/最大为 0.7037/1.0925，主表当前历史分位为
75.41%。行业指数与 PB(MRQ) 组合返回 79 个指数，`SH000004 工业指数`
同样成功展开 484 点。

主表市场号不是只有沪深北：当前 180 行包含上海 67、深圳 92、通达信内部
市场 62 共 21 行。接口将后者原样表示为 `market=tdx-62` 和
`security_id=TDX62:<code>`，不猜测为某个交易所；本地 TNF 能解析 159 个
名称，其余名称保持未解析。原始工作流证据和规范化结果均保存在
`output/probes/relative-valuation-*.json`。

新增测试覆盖数值/空值、日期排序、重复日期、名称回填、描述性分位区间和
内部市场号；全量 CTest 增至 32 项。分位区间仅是客户端侧描述性分桶，响应
明确标记 `investment_signal=false`，不将相对估值位置表述为收益预测。

部署后的功能目录增至 81，服务 PID `16088`，EXE SHA-256 为
`A83024603CE38BAC1FA9983C05164B3ACFF246F1A4B25C2F0D002DBC2A780DA4`。
正式端口单指数冷请求约 1.177 秒，缓存命中约 10 ms；非法指数类型返回
HTTP 400，主页 HTTP 200。部署只替换 C++ EXE，现有 Svelte 构建未覆盖。
