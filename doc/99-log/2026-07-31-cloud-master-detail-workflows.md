# 通达信云功能主表→明细工作流

> 日期：2026-07-31  
> 范围：`cloud_cfg` 的 `masterid` 关系、普通 JSON 与 PBRPC 混合调用

## 目标

此前 `tdx_tqlex.py` 和 `tdx_pbrpc.py` 已能请求单个 ReqId，但调用者仍需
手工从主表复制 `fund_code`、`Code/SetCode` 等字段。新增
`doc/90-scripts/tdx_cloud_workflow.py`，把客户端 XML 已声明的主从关系
固化为可重复执行的工作流。

## 已实现工作流

| 工作流 | 主表 | 明细 | 本次实测 |
| --- | --- | --- | --- |
| `fund-holdings` | JSON `500050` | JSON `500051/500052` | 20 只主表样本；首只基金 4 个行业、46 只股票 |
| `fund-risk` | JSON `500030` | JSON `500031` | 首只基金 48 个交易日 |
| `fund-volatility` | JSON `500032` | JSON `500033` | 首只基金 37 个月 |
| `fund-interval-holdings` | JSON `500055` | JSON `500056/500057` | 6 个行业、9 个报告期 |
| `index-valuation` | JSON `200000` | PBRPC `200001` | 180 个指数；首个指数 484 日 |
| `lhb-details` | PBRPC `500107` | JSON `500108` | 63 条龙虎榜；首条返回上榜原因 |

这六条链全部在不启动 TdxW 的情况下真实返回。结果保存在：

```text
output/tdx-workflow-<工作流名>.json
```

每个输出同时保留主表原始响应、标准化后的选中主行、明细请求和原始响应，
便于继续核对字段。

## 行为

- `--select CODE` 按主键选择基金、指数或股票；指定后自动翻页寻找主记录；
- `--limit` 限制展开的主表行数，默认只展开 1 行，避免意外产生大量请求；
- `--master-all-pages` 可完整下载主表；
- `--set NAME=VALUE` 覆盖工作流默认日期、基金类型、基准或比较方法；
- 基金持仓默认选择最近可靠披露的半年报/年报日期；
- 主表页长与明细页长相互独立，例如 `500052` 继续使用客户端声明的
  `PageSize=400`，不会被主表的 20 行页长截断；
- JSON 和 PBRPC 的 `ResultSets/ColDes/Content` 会统一转换成字段字典，
  但输出仍保留原始响应。

龙虎榜进一步验证了跨协议链：

```text
PBRPC 500107
  └─ SetCode=0, Code=000009
       └─ JSON 500108
            └─ 连续三个交易日涨幅偏离累计达到 20% 的详细说明
```

## 默认时间参数

- 基金收益风险：近 3 个月；
- 基金月度波动：近 3 年；
- 基金区间持仓：最近可靠半年报/年报向前 2 年；
- 指数估值：近 2 年，主题指数、上证指数基准、PE(TTM)；
- 所有默认值均可通过 `--set` 覆盖。

## 下一批原生配置格式

排除 XML 注释后，329 条启用 datasource 的格式分布为：

| reqformat | 数量 | 当前判断 |
| ---: | ---: | --- |
| `1` | 97 | 原生 ABI 已恢复；当前旧服务名未在匿名端直接注册，等待新路由证据 |
| `2` | 73 | 普通 TQLEX JSON；34 个 ReqId 已闭合 |
| `22` | 58 | PBRPC；29 个 ReqId 已闭合 |
| `0` | 50 | 板块/指数等传统命名服务，正文含操作码 |
| `11` | 30 | 已闭合为 7709 `709/1721` 静态文件下载，23 个唯一模板 |
| `20` | 14 | 已确认是本地树控件命令，依赖当前证券/页面上下文 |
| `12` | 6 | 主表驱动的行情/列表补充数据 |

`reqformat=1` 暴露的高价值页面包括：

- 主题驱动事件、事件背景、龙头股和股票集合；
- 概念投资逻辑、一级/二级产业链分类及成分股；
- 基金业绩排行榜、基金指数、基金公司指数；
- 分析师行业指数及最新跟踪成分股；
- 美股 ETF 分类、行情与区间表现。

后续静态分析已校正这份优先级：

- `reqformat=1` 的 TPData 初始化、匿名登录、session、配置、异步请求和
  完成消息已由独立 32 位宿主闭合，但当前匿名端不注册 XML 中的旧直接
  路由；保留宿主等待新版配置或流量给出路由映射。
- `reqformat=11` 实际收益很高：普通 7709 连接可直接下载行业/主题、
  财务估值、资金流、分红、融资融券等资源；行业资源已恢复 5,534 只
  股票、110 个叶子行业和 1,775 个主题。
- `reqformat=20` 由本地树控件执行，不再作为网络协议方向。

详见 [reqformat=1 原生宿主](2026-07-31-reqformat1-native-host.md) 和
[reqformat=11 JSN 资源协议](2026-07-31-reqformat11-jsn-resources.md)。
