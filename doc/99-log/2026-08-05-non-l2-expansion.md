# 非 L2 高价值功能批次：公开资料、股票池、持续行情与旧路由诊断

> 日期：2026-08-05。全部产品代码为纯 C++；网页为 Svelte。没有 Python
> 转发，也没有使用或绕过 Level2 权限。

## 本轮完成的八条方向

1. **ETF 持仓与资金流**：合并 ETF 持股、宽基/主题申赎资金和一级研究行业
   资金，提供全市场、行业与单票反查。当前 89 条 ETF 相关股票；华海药业
   持仓市值约 10.03 亿元，总净流出约 747 万元。
2. **服务端证券目录**：恢复 `0x044E` 总数和 `0x044D` 分页记录。三市当前
   51,918 条（深 23,913、沪 27,637、北 368），包含名称、品种、价格精度、
   每手数量和昨收。
3. **可转债条款**：合并概览、转股进度、票息、回售、赎回、下修及动态历史。
   当前 325 只，剩余余额 4,759.04 亿元；华海药业关联华海转债。
4. **财经与公司日历**：统一宏观数据、热点会议、新股上市和公司事件。当前
   2,771 条；会议可展开成分股，个股可反查相关会议。
5. **员工与高管**：全市场员工、薪酬、研发、人均指标与单票高管名单。平安
   银行当前 41,698 名员工、17 条高管记录。
6. **TPool**：补齐三类排除条件、跨证券排名、按 cell 的无环流程投影和
   `pool watch` 进入/退出告警。原版定时、循环、宿主回调及写回明确不执行。
7. **非 L2 持续行情**：`market watch` 通过公开 `0x054C` 周期读取 L1，按变化
   输出 JSONL；失败时按端点切换和指数退避重连。实测两只证券首轮 2 条，
   无变化的第二轮正确输出 heartbeat。它不冒充 `FastHQ.Subscribe`：后者
   依赖已登录的 tpbus/TaApi `CTAJob_InetTQL` 会话。静态证据确认客户端约
   10 秒重订阅、特定订阅模式约 55 秒重试。
8. **`reqformat=1` 路由诊断**：`cloud routes` 扫描当前安装得到 97 条记录、
   31 个唯一旧服务名；与 `reqformat=2/11/20/22` 没有完全同名入口，排除
   “只改请求格式即可复用”的捷径。统一工具为 x64、`TPData100.dll` 为 x86，
   新诊断会明确报告不能同进程加载以及 Windows 消息循环要求，且不发网络请求。

## 新增网页与接口

- 数据中心：ETF 资金、证券目录、可转债条款、财经日历、员工与高管；
- 个股更多侧栏：对应五类单票关联面板；
- 协议区：`/protocol/pools` 显示 TPool 结构并可触发只读求值，
  `/protocol/routes` 显示旧路由清单和 TPData 宿主边界；
- API：`/api/v1/pools/evaluate` 与 `/api/v1/cloud/routes`。

## 边界

- `FastHQ.Subscribe` 的字段构造已经恢复，但独立工具没有已登录 TaApi 会话，
  因此不发送伪订阅；无需账号的实时需求由公开 L1 watch 提供。
- TPool 流程输出叫“投影”而不是“执行结果”，固定声明运行时语义未经动态
  等价验证。
- `reqformat=1` 当前最有价值的结论是旧路由清单、无同名现代入口和 x86 宿主
  隔离；若未来捕获到新版路由映射，可直接用清单做定点验证，不再盲扫 97 条。
