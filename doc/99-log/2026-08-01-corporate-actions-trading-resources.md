# 公司行动、大宗交易与股权关联主从链

## 目标

继续验证通达信客户端自身的隐藏功能，优先闭合公司行动和交易统计页面的
主表、动态详情路径及股票关联，不扩展 HTML 展示。

## 页面与主表

根据 `.sp` 页签文字和 `.cfg` 字段，确认三组高价值资源：

- `corporate-actions`：28 张表，10,700 行、1,415,390 字节；覆盖最新/拟
  增减持、承诺不减、质押预警和平仓、解押、董监高变动、股份回购、解禁
  和分红日历。
- `block-trading`：7 张表，8,390 行、1,190,395 字节；覆盖月度统计、
  个股成交、近 1/3/6/12 月营业部画像和意向申报。
- `equity-groups`：4 张表，111 行、21,038 字节；覆盖行业、地方国资改革、
  央企整合等整合关系和公司系分组，主表直接携带证券成员串。

共 39 张主表，均从公开 7709 主站下载并通过服务端 MD5。与此前样本去重
后，已验证的高价值 CFG 主表累计为 98 张。

## 动态路径规则

真实元数据探测确认：

| 模板 | 关联键 | 内容 |
| --- | --- | --- |
| `zcjc/<市场><代码>.jsn` | 股票 | 近一年股东增减持 |
| `gqzy/<市场><代码>.jsn` | 股票 | 股权质押完整历史 |
| `cggg/<市场><代码>.jsn` | 股票 | 董监高持股变动历史 |
| `gghg/<市场><代码>.jsn` | 股票 | 港股逐笔回购历史 |
| `dzjy3/<市场><代码>.jsn` | 股票 | 历史大宗成交及买卖营业部 |
| `dzjy13/<市场><代码>.jsn` | 股票 | 大宗交易意向申报历史 |
| `xtzy/<机构ID>.jsn` | 信托/券商 | 该机构的质押证券明细 |
| `dzjy1/<YYYY-MM>.jsn` | 月份 | 当月行业统计 |
| `dzjy2/<月份+行业ID>.jsn` | 月份、行业 | 当月该行业逐股交易 |
| `gdzjc1/<YYYY-MM>.jsn` | 月份 | 每日增持/减持家数 |
| `gqgg/<分组ID>.jsn` | 股权关联分组 | 股票、实控人、控股比例和逻辑 |
| `hgrztj21701/2/3/<年份>.jsn` | 控制单元、年份 | 全市场/A股/港股回购月度趋势 |
| `yybph22401/2/3/4/<营业部ID>.jsn` | 控制单元、营业部 | 近 1/3/6/12 月逐笔交易 |

这里的 `$$UNITID$$` 不是服务器占位符。客户端先用被引用主表的 unit ID
替换它，再把当前行 `$ZQDM` 作为文件名。例如 `func_hgrztj104.cfg` 的三个
引用单元会生成 `hgrztj21701/21702/21703` 三个目录。

## 样本与关联验证

- `SZ000009`：批量请求四类单票详情时，取得增减持 6 条、质押 4 条、
  大宗交易 1 条；没有意向申报时返回长度 0，并被 `--skip-missing` 正常跳过。
- `SH603733`：`cggg/1603733.jsn` 返回 19 条董监高变动；横向查询共命中
  35 个资源、90 条记录。
- `31|02378`：`gghg/3102378.jsn` 返回 494 条港股回购历史；两位市场号
  已能从拼接路径正确拆出，横向查询连同主表共 495 条。
- `hyX41/gl197/xl316`：股权关联详情分别返回 23/34/19 只证券，并含
  实控人、控股比例和逻辑说明；`dq529` 当前服务器没有生成详情，主表成员
  串仍可直接使用。

当前保存 27 个动态样本、768 行、88,442 字节。全目录编目为 190 个资源、
114,595 行、24,331,753 字节。

## 工具变化

- `download_tdx_jsn.py` 新增 `corporate-actions`、`block-trading`、
  `equity-groups` 三个资源族。
- CFG 清单可展开 18 种新增动态模板，统一清单从 547 增至 565。
- 新增 `--skip-missing`，适合批量尝试一只股票的多个稀疏详情。
- `--market` 支持两位海外市场号；目录解析已覆盖当前数据中的
  `28/29/30/31/44/48/66`。
- `catalog_tdx_jsn.py` 和 `query_tdx_jsn.py` 可识别股票、月份、行业期、
  机构、营业部、年份和股权分组参数。
