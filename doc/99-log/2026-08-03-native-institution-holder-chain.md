# 机构持仓与股东跨股票链纯 C++ 迁移

日期：2026-08-03

## 目标

把此前由 Python 验证的“单票机构历史 → 十大流通股东 → 选定股东跨股票
持仓 → 选定股票逐报告期变化”迁入统一 C++ 工具和 Svelte 个股页面。运行时
不读取 Python 产物，也不把旧脚本作为子进程。

## 上游链路

1. `cgfxmx1/<市场号><代码>.jsn`：单票机构分类持仓历史；
2. `cgfxmx2/<市场号><代码>.jsn`：十大流通股东及 `gdjc` 入口；
3. `CWServ.tdxf10_gg_gdyjcgmx` + `gdjc`：按 `gdid` 反查股东跨股票历史；
4. 同一 Entry + `gdjcxq`：展开股东在选定股票的逐报告期历史。

股东接口使用 `http://page1.tdx.com.cn:7615/TQLEX`，请求体为：

```json
{"Params":["gdjc","603221","QF000034","","1"]}
```

或：

```json
{"Params":["gdjcxq","603221","QF000034","","1"]}
```

响应列名位于 `ResultSets[0].ColName`，记录位于 `Content`。当前主站直接返回
正确 UTF-8；实现不对正常中文强制二次转码。

## 原生实现

- 新增 `market institution` 子命令；
- `/api/v1/security/profile` 升级为批量抓取、规范化和五分钟缓存；
- 新增只读 `/api/v1/market/holder`，支持 `offset/limit`、选定股票和强制刷新；
- 解析 `gdjc` URL 中的 `gdid`、可选 `tdxid`、`gdname` 和 `gp`；
- 将变化类型 `1/2/3/4` 规范化为“新进/不变/增持/减持”；
- 跨股票全量结果缓存 15 分钟，但单次网页最多返回 500 条，当前页面固定 50 条；
- `gdjcxq` 只在用户点击股票时获取，避免对全部关联股票批量展开。

Svelte 的“股东与机构”页签在十大流通股东表增加“跨股票”入口。展开后显示
关联股票数、当前持有记录、分页历史和选定股票的逐报告期变化；点击历史中的
另一只股票即可切换报告期详情。

## 真实验收

样本：`SH603221 爱丽家居`，股东 `QF000034 高盛公司有限责任公司`。

- 机构分类历史：15 条；
- 十大流通股东：10 名，10 名均可解析股东入口；
- 高盛跨股票历史：1,579 条、1,579 只唯一股票；
- 当前股票报告期：5 条；
- 首条关联为 `SH688657 浩辰软件`，报告期 `2026-07-23`；
- 当前股票最新一期为 `2026-03-31`，持股 1,359,308 股、占比 0.56%、增持
  523,500 股；
- 本地服务冷请求：profile 约 145 ms，股东主链加当前股票约 323 ms；
- 同一股东下一页命中缓存约 5 ms。

## 测试边界

原生测试覆盖：

- URL 百分号解码及 `gdid/tdxid/gp` 提取；
- `ColName + Content` 数组转对象；
- 市场号到 `SH/SZ/BJ` 证券键的映射；
- 跨股票与单票报告期的中文、占比及变化类型归一化。

发布后的功能注册数为 24，生产服务进程仍只包含 `tdx-tool.exe`，不依赖
Python、Node.js 或预生成的股东历史 JSON。
