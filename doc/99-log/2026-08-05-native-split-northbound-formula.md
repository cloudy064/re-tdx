# SPLIT 除权序列与“陆股通净买”公式闭合

> 日期：2026-08-05。运行时实现为纯 C++；IDA Python 仅用于离线核对
> `TCalc.dll` 求值器，不进入发行包和服务进程。

## 结论

- `DAYSTOTODAY` 对应 `TCalc!sub_100171A0`，返回本机当天与每根 K 线日期的
  自然日差；
- `SPLIT` 对应 `TCalc!sub_10012A50`，`SPLIT(N,0)` 返回第 N 个送转事件的
  `送转数/(送转数+10)`，`SPLIT(N,1)` 返回每股现金分红；
- `SPLITBARS` 对应 `TCalc!sub_10012C60`，按第 N 个匹配除权事件计算到当前
  K 线的实际根数，事件当天为 0；类型 0/1/2 分别筛选送转、现金分红、任一；
- 三个求值器读取宿主 type `164` 的 29 字节除权记录。纯 C++ 上下文复用已验证
  的 `0x000F` 公司行动记录，按日期和事件次序生成 `SPLIT#N#TYPE`、
  `SPLITBARS#N#TYPE` 序列；没有匹配事件时保持空值，不伪造 0。

## 真实数据验证

平安银行 `SZ000001` 的 800 根日线验证结果：

- 识别 32 条除权除息事件，最早 `1990-03-01`，最新 `2026-06-12`；
- 2026-06-12 识别每 10 股派 3.6 元，`SPLIT(0,1)=0.36`、
  `SPLITBARS(0,1)=0`；
- 2026-08-05 对同一现金事件的周期为 37 根日线，`DAYSTOTODAY=0`；
- 系统公式“陆股通净买”完整执行，800 根日线中有 321 个非零结果；最近
  非零点为 2026-06-30，公式输出 `167578.3918` 万元，约 16.76 亿元。
