# 龙虎榜事件与营业部席位纯 C++ 聚合

## 目标

把旧 `update_tdx_lhb.py` 的 8 张龙虎榜分析主表和动态事件详情迁入
`tdx-tool.exe`。查询结果必须按事件保留上榜原因，不能把同一股票、同一
日期的不同事件静默合并，也不能依赖旧 Python JSON。

## 数据链

8 张主视图为龙虎榜还原、机构参与、市场风口、合力封板、一家独大、量化
席位、同城携手和游资席位。每行的 `$ZQDM` 是事件 ID，`$SC1/$ZQDM1`
是证券键；详情路径为：

```text
lhbfx/<事件ID>.jsn
```

详情保留营业部、买卖方向、排名、买入额、卖出额、净买入、成交占比、
近 1/3/5 日买入成功率、估算成本和收益，以及买入/卖出合计行。

## 实现

- 新增 `native/include/tdx/lhb.hpp` 与 `native/src/lhb.cpp`；
- `fetch_jsn_resources_rows` 允许同一 7709 连接批量读取多个 JSN，主表不再
  为 8 个资源逐个重连；
- 新增 `market lhb`，支持 `--market/--code` 或 `--event`；
- 新增固定 API `/api/v1/market/lhb`；
- 主表按事件 ID 聚合视图、上榜原因、日期和所有候选证券键，市场键冲突
  显式保留；详情存在时仍按事件独立展示；
- 服务端主表缓存 60 秒、事件详情缓存 300 秒；
- Svelte 个股“更多”抽屉新增“龙虎榜”页签，仅打开时加载，停留时每分钟
  检查主表更新。

## 真实验收

- 最新 8 张主表：271 条视图行、123 个事件、105 只股票、2 个证券键冲突；
- 批量主表冷进程约 1.03 秒；
- `SH688066 *ST航图` 命中同日两个独立事件 `3726245/3726235`，分别对应
  连续三日偏离和单日涨幅原因，共取得 24 条详情；
- 每个事件均为买五、买入合计、卖五、卖出合计 12 行，中文营业部名称、
  金额、净额、占比和历史成功率均正确解码；单票冷进程约 0.71 秒；
- 事件级金额不跨事件合并，避免同股同日的重复详情造成双计。
- 生产 API 冷请求为 458 毫秒，紧接的同参数请求为 17 毫秒；首次刷新
  8 张主表和 2 个事件详情，第二次主表未刷新、详情刷新数为 0。无事件的
  `SZ000001` 正常返回空数组而不是报错。

## 测试与边界

- 原生单元测试覆盖跨视图事件聚合、证券名称解析、席位行和合计行分类；
- `ctest` 全部通过，`svelte-check` 为 0 错误、0 警告，Vite 构建成功；
- 生产服务已部署到 `127.0.0.1:8765`，功能目录为 23 项，OpenAPI 和最新
  Svelte 资源均已验证；
- 该能力是公开龙虎榜和营业部统计，不是 Level2 逐笔或委托队列；
- 主视图只代表当前服务器窗口，空结果表示当前 8 张视图没有该证券，不等于
  证券历史上从未上榜。
