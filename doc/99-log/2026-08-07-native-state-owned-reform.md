# 国企改革分层关系、控制人和重组预期纯 C++ 固定化

## 结论

`GQGG.sp` 不是本地“国企改革”概念块的重复页面。客户端实际维护四套分层关系：
按行业、按地区、整合预期和公司系，并通过动态 `gqgg/<分组ID>.jsn` 展开成员的
实际控制人、控股比例、阶段收益参考价、领涨次数和投资逻辑；另有一张独立的
重组预期表。

本轮新增纯 C++：

- CLI：`tdx-tool market state-owned-reform`；
- API：`/api/v1/market/state-owned-reform`；
- Svelte 数据中心“国企改革”页面；
- 个股工作台“股东与股权”中的国企改革关系面板；
- 三项正式 API 契约和独立原生单元测试。

运行时不调用 Python，也不修改通达信安装目录。

## 产品化边界

接口提供 `groups/group/security/restructuring/catalog` 五种视图：

- 分组视图可切行业、地区、整合预期和公司系，支持文本过滤、成员数排序与分页；
- 分组详情只为所选分组下载动态资源，并批量补齐成员公开行情；
- 单票视图反查其全部改革分组、动态控制关系和重组预期；
- 重组视图保留资本运作、说明、控制人、控股比例、净利润和日期；
- 静态分组、动态详情或行情任一失败都在 `sources/errors/availability` 中显式报告。

网页左侧呈现分组和成员摘要，右侧按需展示控制人、控股比例、投资逻辑及阶段
表现；个股工作台复用同一接口，没有复制一套前端推断逻辑。
