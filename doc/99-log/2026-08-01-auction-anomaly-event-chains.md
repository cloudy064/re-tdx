## 动态主从链

真实验证七种模板：

```text
经济指标 -> jjzb1/<指标ID>.jsn       历史数值走势
经济指标 -> jjzb2/<指标ID>.jsn       关联行业与股票
股票 -> ggjx/<市场><代码>.jsn        精选公告历史
行业/区域组 -> ydyl1/<分组ID>.jsn    股票、逻辑与说明
专题 -> ztxx/<专题ID>.jsn             完整信息时间线
强势区间 -> ygzl/<区间ID>.jsn        逐日涨停原因与市场温度
新闻/部委事件 -> sjqd/<事件ID>.jsn   关联股票
```

10 个动态样本共 676 行、133,922 字节。PVC 期货结算价指标返回 100 个
历史点和 470 只关联股票；2026 年半年报专题返回 39 条完整信息；
`IGCC技术`、`风沙治理` 两组返回逐股投资逻辑；股票 `SZ000078` 返回
20 条精选公告历史。

查询工具已把指标 ID、机会组 ID、专题 ID、强势区间 ID 和新闻事件 ID
还原为主表名称与上下文：

- `SH603970` 可显示其关联“聚氯乙烯(PVC):期货结算价”；
- `SZ000777` 可显示 `IGCC技术` 机会组及逐股逻辑；
- `SZ300223` 可显示三星 HBM4 事件及事件成员关系。
