# 成交明细与正式竞价闭合

## 目标

把此前只确认可请求的 `0x0FC5/0x0FC6` 成交明细正式工具化，并用
09:25、15:00 集中撮合记录闭合 `0x056A` 最后虚拟样本之后的正式开盘、
收盘竞价价量额。

## 请求与响应

当日成交 `0x0FC5` 请求体为 12 字节：

```text
uint8 market
uint8 zero
char[6] code
uint16 start
uint16 count
```

历史成交 `0x0FC6` 请求体为 16 字节：

```text
uint32 yyyymmdd
uint16 market
char[6] code
uint16 start
uint16 count
```

当日响应先给 `uint16 count`；历史响应再多一个 `float32 price_base`。
随后每条记录依次为：

```text
uint16 minute_of_day
signed_varint price_delta
signed_varint volume
signed_varint order_count
signed_varint status
signed_varint tail
```

价格在每个响应页内从零累加。普通股票除以 100；ETF、债券除以 1,000。
因此顺带修正了 `tdx_market_snapshot.py` 对债券三位小数价格的遗漏。

## 分页方向与服务端上限

`start=0` 指向最新记录块，增加 `start` 会向更早的记录回溯；但每个响应
块内部仍按时间正序。服务端即使请求 2,000 条，当前最多也只返回 1,800
条，因此不能把“短于请求数”当成结束。正确算法是：

1. 按实际返回条数推进 `start`；
2. 继续请求，直到返回空页；
3. 将页块倒序拼接，保持每页内部顺序不变。

平安银行以 100 条小页取得 4,644 条，以默认请求取得 1,800 + 1,800 +
1,044 条；两种分页的总量、金额和竞价记录完全一致。

## 当日与历史一致性

在服务器交易日 `20260731`，对平安银行、陇神戎发、传智教育、立方控股
同时请求 `0x0FC5` 与 `0x0FC6`。四只共 11,406 条，逐字段序列全部一致，
包括价格、量、笔数、状态与尾字段。

该协议时间精度只有分钟，且单条记录带聚合后的 `order_count`，属于公开
L1 成交明细，不是带秒级时间戳的 Level2 逐笔成交或逐笔委托。

## 正式开盘与收盘竞价

真实股票样本中：

- 09:25 通常恰有一条 `status=2` 中性记录，给出正式开盘竞价价、量、额；
- 15:00 通常恰有一条 `status=2` 中性记录，给出正式收盘竞价价、量、额；
- 深市样本在 15:05—15:30 还可能出现 `status=5`，这是盘后定价成交，
  已单独汇总，不能混入 15:00 收盘集合竞价。

抢筹最高 30 只的验证结果：

- 09:25 成交价与 `0x054B` 正式开盘价：`30/30` 在 0.001 元内一致；
- 09:25 成交量与 `tdxstat2`：`30/30` 在 1 手内一致；
- 精确成交额与分类/统计压缩金额：`30/30` 在 1,000 元内一致；
- 15:00 成交价与分类行情正式收盘价：`30/30` 一致；
- 26 只存在深市 `status=5` 盘后定价成交。

陇神戎发的闭合示例：

```text
14:59:51 虚拟匹配：13,590 手（收盘竞价段）
15:00 正式撮合：   15,595 手，13.73 元，21,411,935 元
最后 9 秒新增：     2,005 手
```

## 无 09:25 成交的边界

抢筹最低 30 只中，北交所 `BJ920271`、`BJ920675` 没有 09:25 记录，
首笔成交均在 09:30。它们提供了一个关键反例：

```text
BJ920271：09:24:57 虚拟价 10.50，匹配量 110 手
           正式开盘价 9.24，首笔成交 09:30
           分类/统计“开盘金额”仍为 115,500 = 10.50 × 110 × 100
```

所以 `0x054B/tdxstat2` 的字段应称为“竞价参考量额”：有 09:25 撮合时它
近似正式成交量额；无撮合时可能保留最后虚拟匹配值。质量工具现在输出：

- `executed-0925`：存在正式开盘集合竞价，可给出正式量额；
- `no-0925-trade`：没有正式开盘集合竞价，正式量额保持空值；
- `auction_reference_*`：无论是否执行都保留原生竞价参考口径。

最低榜其余 28 只均有 09:25 记录，正式开盘价 `28/28` 匹配；全部 30 只
均有 15:00 记录，正式收盘价 `30/30` 匹配。
