# A股表现、股东信号、特色财务、GDR与基金日历闭环

本轮从剩余 179 个未类型化且未下载模板中选择 19 个高价值候选做元数据探测，
14 个非空、5 个当前不存在。14 个非空资源全部由纯 C++ `jsn download` 下载、
校验 MD5 并纳入固定业务命令，没有 Python 转发。

`AGHQ101` 经 `func_aghq101.cfg` 校准为全 A 股表现，而不是主要指数。新命令
`market equity-performance` 返回 5,539 条，沪/深/北分别 2,311/2,895/333，
包含收盘价、当日/5日成交额、5/20/60日、本月和年初至今涨幅及 PE。本月涨幅按
`(price0-price1)*100/price1` 复算；现价、当日涨幅、总市值和行业是宿主列，
静态 JSN 中不存在，因此没有伪造。

`market shareholder-signals` 固定 `CWNSCG101/JGXC101/JGZD101` 三表，共
1,039 条、1,022 只去重股票：912 条牛散聚合持股、45 条机构增持且股东户数
收缩、82 条利润成长与机构调研活跃。牛散持股比例/金额、机构持股和股东人数
变动按 CFG 复算；JGXC 源比率另输出乘 100 后的百分点字段。

`market financial-insights` 固定八类 1,151 条、972 只股票：巴菲特质量 6、
高送转潜力 39、投资性房地产 451、低市销率 20、分红不足 123、股权投资 200、
现金高于市值 15、高应收账款 297。万元金额乘 `1e4`、亿元金额乘 `1e8`，
高送转最新股本从万股换算为股；投资性房地产环比、分红/利润、研发/收入、
现金/市值等公式均由源字段复算并保留 raw 审计行。

`market gdr` 固定 23 条 GDR/A 股映射，包含行情日、币种、上市地点、发行量、
兑换比例、A 股标的、源折算价和溢价率。价格与溢价明确是源行情日快照，没有
使用当前汇率重新解释。`market fund-calendar` 固定 315 条、261 只基金事件，
覆盖 7 类事件和 5 类基金；市场 33 规范为场外 `fund`，场内基金保留沪深市场。

五个命令均有固定 API 和 Svelte 数据中心页面；A 股表现、股东信号、财务线索、
GDR 同时接入个股工作台。验证结果为原生测试 85/85、Svelte 检查 0 错误/0 警告、
新增 API 与网页契约 7/7。JSN 覆盖升至 451/616，470 个文件匹配 415 个模板，
解析错误 0，已下载模板通用独占 0。

正式构建已安装并重启到 `127.0.0.1:8765`。正式实例的新功能契约仍为 7/7，
全量 API 契约为 120/120（121 次网络请求、0 失败）；健康检查确认运行时加载
