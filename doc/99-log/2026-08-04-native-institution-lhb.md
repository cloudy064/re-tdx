# 机构龙虎四周期统计纯 C++ 迁移

## 目标

迁移客户端“机构龙虎统计”，同时避免与已经实现的逐事件、逐营业部龙虎榜
混为一谈。新功能负责滚动周期机构席位排行和股票异动日总额；现有
`market lhb` 继续负责上榜事件及买五卖五营业部。

## 页面与动态键

- `JGLHTJ.sp` 明确四个页签：最近一周、一月、三月和一年；
- `func_jgzc101..104.cfg` 分别使用单元 `22801..22804`，主表为
  `list/func_jgzc101_1.jsn` 至 `func_jgzc104_1.jsn`；
- `func_jgzc105.cfg` 声明 `refunit="22801,22802,22803,22804"` 和
  `file="lsyd$$UNITID$$"`，因此详情目录必须随周期替换单元号；
- 四个周期详情路径分别为
  `lsyd22801..22804/<市场号><六位股票代码>.jsn`。

主表 `jgmr/jgmc` 是机构席位买入/卖出金额，`jgcys` 是机构参与数；空金额
按客户端计算列语义视为 0，净额为买入减卖出。详情 `bje/sje` 的 CFG 名称
只是异动日“买入金额/卖出金额”，真实数值是当日龙虎榜买卖总额，因此字段
命名为 `event_total_*`，不与主表机构额求和或做一致性断言。

## 原生与网页实现

```powershell
tdx-tool market institution-lhb --root C:\new_tdx --period year `
  --direction net-buy --limit 50

tdx-tool market institution-lhb --root C:\new_tdx --period week `
  --market sh --code 601003 --details
```

固定 API 为 `/api/v1/market/institution-lhb`。四张主表批量读取并缓存 5 分钟，
周期动态详情及不存在结果缓存 15 分钟；调用者不能传任意资源路径。

网页按用户新设计的 `Navbar + MarketDataHub` 架构接入：数据中心增加“机构
龙虎”胶囊入口，提供四周期卡片、方向筛选、排行和动态详情；个股全景抽屉
增加可切换周期的“机构龙虎”页签。同期把新版 UI 的 API 字段绑定从 38 个
类型错误修正为 0，并修正行情价格重复除以 100、五秒刷新重复拉取 K 线两个
回归问题，未改变新版布局和视觉样式。
