标签、快捷页顺序和资源单元 ID，可以先恢复完整功能族，再做一次连接内的

## 龙虎榜主表与隐藏详情

`LHBFX.sp` 恢复的页面为龙虎榜还原、机构参与、市场风口、同城携手、
合力封板和一家独大；CFG 还提供量化席位和游资席位。8 张主视图行数依次
为 80、42、30、1、65、42、41、48，共 349 行。

这些不是 349 个独立事件。以隐藏列 `$ZQDM` 为事件 ID 聚合后得到：

- 147 个唯一事件；
- 118 只股票；
- 349 条事件—视图成员关系；
- 99 个事件同时属于多个视图，最多同时命中 6 类。

详情 CFG 单元使用 `file="lhbfx"`，字段 `$ZQDM` 标为“关联ID”。真实路径为：

```text
lhbfx/<事件ID>.jsn
```

详情含市场、日期、上榜类别、营业部、买卖方向、排名、买入额、卖出额、
净买入、成交占比、近 1/3/5 日买入成功率、估算成本和收益。当前已验证
5 个事件、56 条营业部记录。以 `603221` 为例，事件 `3725663` 返回 8 条，
事件 `3725533` 返回 12 条；同一股票因此能同时保留多个上榜日和视图分类。

主视图存在三个市场号冲突事件：`3725223`、`3725263`、`3725253`。工具
不静默覆盖，而是保留 `market_candidates` 和冲突标志；详情下载成功时以
详情记录中的市场号为权威值。另有两个事件的详情载荷完全相同，说明同一
股票同日可能由不同事件 ID 引用同一组营业部记录，不能只按 MD5 合并事件。

## 工具

```powershell
# 按已验证资源族更新主表
python doc/90-scripts/download_tdx_jsn.py `
  --root C:\new_tdx --family institution-holdings --download

python doc/90-scripts/download_tdx_jsn.py `
  --root C:\new_tdx --family shareholder-counts `
  --family lhb-analysis --family capital-strength --download

# 更新 8 张龙虎榜主视图并生成事件/股票双向模型
python doc/90-scripts/update_tdx_lhb.py `
  --root C:\new_tdx --download-masters --compact

# 只取一只股票涉及的营业部详情
python doc/90-scripts/update_tdx_lhb.py `
  --root C:\new_tdx `
  --download-details --market 1 --code 603221 --compact

# 横向查询该股票的全部已下载 JSN 功能
python doc/90-scripts/query_tdx_jsn.py `
  --root C:\new_tdx --market 1 --code 603221 `
  --output output\tdx-603221-features.json
```

`--family` 可重复使用并自动启用 CFG 清单。龙虎榜详情也可用
`--event <事件ID>` 精确选择；默认最多下载 50 个事件，只有显式指定
`--all-details` 并提高 `--max-details` 才会扩大范围。

加入 4 个单票机构详情样本后，当前离线编目合计 127 个资源、95,354 行、
21,714,933 字节。示例输出为
`output/tdx-lhb-events.json`、`output/tdx-603221-features.json` 和
`output/tdx-000063-features.json`。
