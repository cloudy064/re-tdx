# 实际/预告利润、现金流质量与业绩反转闭环

> 日期：2026-08-08。范围：公开 JSN、客户端 CFG、纯 C++ CLI/API、Svelte
> 数据中心和个股工作台；不依赖 Python 或 Level2。

## 配置语义

`func_knzx101.cfg` 是退市财务风险相关的实际/预告利润筛选。客户端明确说明
“实际净利润”取扣非净利润与净利润中的较小者；JSN 直接下发这一结果，而未下发
两个组成项，因此接口保留 `actual_profit_yuan`，不伪造组成利润。其余字段为
报告期/类型、净资产、营业收入、下一预告期、利润上下限和预计披露日。

`func_xjl101.cfg` 是现金流质量筛选，客户端列出四个同时满足的条件：

- 每股经营活动现金净额大于 0；
- 经营活动现金净额与短期债务比率大于 50%；
- 经营活动现金净额与净利润比率大于 100%；
- 存货与流动资产比率小于 50%。

接口逐项输出布尔判定及总判定，同时保留自由现金流、经营现金总额、资产负债率、
流动/速动比率源值、利息保障倍数和市盈率。自由现金流不是上述四项门槛之一，
因此出现负值时也不会被错误过滤。

`func_yjfz101.cfg` 是业绩反转表。已披露年度利润/收入在预告场景使用上下限均值，
下一年度数据来自近六月机构研报综合预测。当前增长率可精确按
`(下一年预测利润 - 已披露利润) / abs(已披露利润) * 100` 复算；目标涨幅依赖
宿主实时现价，静态源不含现价，因此只保留目标价，不伪造目标涨幅。

1,464，新增视图：

- `--view profit-warning`：实际利润、预告区间/中值和披露日；
