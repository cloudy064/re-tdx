# TCalc 六类筹码分布函数原生闭环

> 日期：2026-08-05。运行时实现位于 `native/src/formula_engine.cpp` 和
> `native/src/formula_context.cpp`，仅使用纯 C++ 与通达信公开行情协议。

## 恢复结果

从 `TCalc.dll.i64` 的函数注册表定位到以下执行入口：

| 函数 | 执行入口 |
| --- | ---: |
| `COST` | `0x1001F0A0` |
| `COSTEX` | `0x1001FD10` |
| `WINNER` | `0x10020580` |
| `PWINNER` | `0x10020CC0` |
| `LWINNER` | `0x100213F0` |
| `PPART` | `0x10021B90` |

六个入口现已全部进入纯 C++ 解释器。它们都内含完整计算循环，并非向宿主
查询成品筹码值。共同算法如下：

1. 用本次计算全部日线的最低价和最高价建立 0.01 元价格网格；
2. 每根日线先按 `1 - VOL/CAPITAL` 衰减历史筹码；
3. 把本日成交量按最低价到中间价递增、中间价到最高价递减的三角权重加入；
4. `WINNER(P)` 返回价格不高于 `P` 的累计筹码占比；
5. `COST(N)` 返回累计筹码首次越过 `N%` 时的价格。

另外三个函数逐项保留了各自不同的窗口语义：

- `PWINNER(N,X)`：先把筹码分布推进到当前柱之前 N 根，再用当前柱的 `X`
  计算远期获利盘；
- `LWINNER(N,X)`：每个输出柱清空分布，只用最近 N 根日线重新构造近期筹码；
- `COSTEX(A,B)`：分别累计价格不高于 A/B 的筹码量和价格加权和，再以两者
  差值计算区间筹码的平均成本。

这三个边界直接来自 `0x10020CC0/0x100213F0/0x1001FD10` 的循环、指针偏移
和输出位置，并与通达信官方函数签名一致；没有把它们近似成 `WINNER` 的别名。

`PPART(N)` 位于相邻的 `sub_10021B90`：输出第 i 根时，对
`[i-N,i)` 的 `1-VOL/CAPITAL` 以原生 float 精度逐项连乘，表示 N 周期前筹码
仍留存的比例。该入口没有调用其他五个价格网格函数使用的日线周期拒绝检查，
因此解释器也允许它在其他周期执行，而不是人为增加不属于 TCalc 的限制。

实现逐项保留反编译中确认的 `float` 输入收窄、`0.503000020980835` 端点舍入、
`1e-5` 判定阈值和 `50,000,000` 格次工作量上限。没有采用网上常见的固定
衰减系数、均价单点或平均分布近似。

## 历史流通股本

筹码入口唯一的业务数据回调是类型 `103`。回调接收逐日日期数组，并返回每个
交易日的流通股本；函数随后以成交量除以该值取得换手比例。

纯 C++ 上下文现在自动组合：

- `0x0010` 批量财务基础信息：取得当前流通股本；
- `0x000F` 股本变迁：读取每次变更前、变更后的流通股本；
- K 线交易日：把变更节点展开为逐日 `CAPITAL`，单位转换为手。

平安银行在线样本共返回 79 个公司行动事件，其中 46 个携带有效流通股本前后
值，覆盖到 2025-06-30。公式结果的 `context_metadata` 会返回
`capital_series_mode=tdx-0x000f-historical`、有效事件数和首末事件日期，便于
调用方审计数据来源。

## 覆盖与验证

新增可执行公式共 11 条：

- 技术指标：`CYD`、`CYQKL`、`ZJTJ`、`SCR`、`ASR`；
- 条件选股：`COSTXG`、`PRD`、`PRX`、`ASRD`、`ASRX`、`C120`。

含真实只读上下文的覆盖从 291 提升至 302：技术指标 `161/222`、条件选股
`102/107`、专家系统 `15/15`、五彩 K 线 `24/35`。平安银行 800 根日线的
整库审计结果为 `302/302` 通过、0 个运行错误、0 个空序列、302 个有效末值。

边界测试使用单根 `10.00—10.06` 日线，原生三角网格得到
`WINNER(10.03)=0.75`、`COST(50)=10.024`、
`COSTEX(10.03,10.02)=10.03`。两根跨价格区间的测试进一步验证
`PWINNER(1,CLOSE)=1.0`、`LWINNER(1,CLOSE)=0.8`；后者保留全局一分钱网格下
六个价位和 `+0.503` 中点舍入产生的非对称边界。解释器对五个函数的非日线
调用统一返回明确错误。官方语义见
[通达信公式函数列表](https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html)。

平安银行 120 根真实日线的六函数组合也已通过：2026-08-05 最新结果为
`WINNER=0.79127979`、`PWINNER(5)=0.87080145`、
`LWINNER(5)=0.03861080`、`COST(50)=10.97590351`、
`COSTEX(CLOSE,REF(CLOSE,1))=11.35375881`、`PPART(5)=0.95645773`，上下文
使用 46 个真实股本事件。
