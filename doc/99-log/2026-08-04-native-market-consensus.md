`2920179` 可下载。

## 纯 C++ 实现

- 新增 `market consensus`，不依赖 Python 或预下载文件；
- 六张主表复用一条 7709 会话并分别保留榜单语义；
- 主表规范化证券名称、行业、评级、目标价、估值和三年预测；
- 单票详情规范化报告日期、机构、机构等级、分析师、评级变化、目标价、
  三年预测和研报正文；
- 提供代码/名称/行业筛选，单票模式返回其六榜归属；
- 主表缓存 5 分钟、单票详情缓存 15 分钟；可选择省略长正文；
- 固定 API 为 `/api/v1/market/consensus`；Svelte 同时提供独立榜单页和个股
  “预期研报”侧栏。

协议测试覆盖北交所 `44 → BJ/2` 映射、三年预测、报告倒序和正文省略。

## 边界

- 评级分数、目标价和预测数值均保留通达信原始口径，不构成投资建议。
- 某股票不一定进入当前六张榜单，但只要服务端存在动态详情仍可按代码查询。
- 研报正文体积明显大于主表；单票响应已收敛为当前证券的一条主表记录，
  不再附带完整 319 行榜单。
