# CFG 隐藏 JSN 主表与高价值功能

> 日期：2026-07-31  
> 范围：`T0002/cloud_cfg/*.cfg` 的 `<unit file="*.jsn">`、7709 命令
> `709/1721`、离线字段编目与单证券反查。  
> 结论等级：资源发现来自本地配置；首批样本由普通 Python 直连、长度和
> MD5 校验以及真实内容解析共同验证。

## 发现

此前资源清单只扫描 XML datasource 的 `reqformat=11`，得到 23 个模板，
其中 21 个为无占位符静态表。战略主题主表证明列表 CFG 本身还有另一层
资源声明：

```xml
<unit id="..." style="list" file="func_xxx_1.jsn">
```

扫描全部 CFG 后的去重结果：

- XML 模板：23 个；
- CFG 候选：542 个；
- 合并清单：544 个；
- CFG 独有：521 个；
- XML 独有：2 个动态详情模板。

这些是“候选”而不是 542 个都已确认在线有效。为控制请求量，只从中挑选
30 个高价值名称执行命令 709 元数据探测，26 个当前返回非零长度；随后
下载 24 个样本，共 3,475,722 字节、28,102 行，全部通过 MD5。

## 工具

```powershell
# 不联网：统一列出 XML 与 CFG 资源
python doc/90-scripts/download_tdx_jsn.py `
  --root C:\new_tdx --list --include-cfg

# 小批量探测或下载
python doc/90-scripts/download_tdx_jsn.py `
  --root C:\new_tdx --include-cfg --probe `
  --match 'func_scrd101|func_cgfx101|func_gdrs101'

python doc/90-scripts/download_tdx_jsn.py `
  --root C:\new_tdx --include-cfg --download `
  --match 'func_scrd101|func_cgfx101|func_gdrs101' --summary
```

`--include-cfg` 只扩展发现清单，不自行下载。单次联网默认最多 100 个资源；
超过时必须缩小范围或显式调整 `--max-resources`。目前不建议对 542 个候选
执行无差别全量探测或下载，应继续按功能族和实际用途选择。
