# 服务端封板榜、统计资源与封单质量闭环

## 目标

继续探索通达信原生功能，把服务端封单额排序、历史封单和自由流通股本
接入现有涨停质量工具，并解决 `tdxstat2.cfg` 跨交易日字段容易错取的问题。

## 0x054B 服务端分类排序

请求数据固定为九个小端 `uint16`：

```text
category, sort_type, start, count, sort_reverse, 5, filter_raw, 1, 0
```

客户端通常把 A 股分类 `6` 标作“沪深 A 股”，但当前主站实际还返回
北交所；封单额、开盘抢筹的排序号分别为 `0x001C`、`0x010A`。响应头为
两个 `uint16`，随后是变长基本行情、买一/卖一和
56 字节固定尾部。已在 `tdx_category_quotes.py` 中实现 16 类中英文排序
别名、主站切换、严格边界解析和默认 dry-run。

2026-08-01 对 2026-07-31 收盘数据实跑封单额降序：

- 第 1 页 80 条全部满足买一等于现价、卖一为空；
- 第 2 页前 21 条仍封板，第 22 条开始是普通买盘；
- 连续封板前缀共 101 只，与 `func_zdtfx107_1.jsn` 的 `ztjs2=101`
  完全一致；
- 市场分布为深圳 52、上海 48、北京 1，不能按“沪深”名称丢弃北交所；
- 前 80 只另用 `0x0547` 查询，80 个买一金额全部逐分相等，最大绝对差 0；
- 榜首蓝色光标当前封单 389,382,945 元，末位威龙股份 211,104 元。

工具因此增加 `--all-sealed`：按页扫描但只保留连续封板前缀，遇到第一条
非封板证券立即停止；另设十页安全上限。开盘抢筹前 30 名也已实跑，
`opening_rush` 从 13.90 到 3.18 严格降序。

## 0x06B9 与 zhb.zip

`0x06B9` 请求为 `uint32 offset + uint32 size + 300 字节 ASCII 路径`，
响应为 `uint32 chunk_len + content`。`tdx_stats.py` 默认每次取 30,000
字节，在同一连接上连续下载；单块上限 60,000 字节，并限制 ZIP 总大小、
入口数、单入口/总解压大小、加密和重复成员。

在线 `zhb.zip` 实测：

| 项目 | 结果 |
| --- | ---: |
| ZIP 字节数 | 1,397,321 |
| `tdxstat.cfg` 行数 | 7,957 |
| `tdxstat2.cfg` 行数 | 7,957 |
| 主统计日 | 2026-07-31 |
| 主统计日覆盖率 | 99.4470% |

本机 `hq_cache` 两表仍各 7,953 行，主统计日为 2026-07-29。在线资源
明显更新，不能默认使用本地缓存做当日短线指标。

关键列映射已经固化：

- `tdxstat.cfg`：60 日 Beta、PE-TTM、自由流通股本、年内涨停天数、
  统计窗口、窗口涨停数和连板天数；
- `tdxstat2.cfg`：当日/昨日/前日成交额与封单、当日/昨日竞价量、
  当日/昨日开盘金额。

## 日期对齐

统计行日期与目标事件日相同时，“昨日值”必须取 `prev_*`；统计行日期为
上一交易日时，才把当行的 `amount/seal_amount/open_*` 作为昨日值，再把
其 `prev_*` 作为前日值。工具输出 `same-day`、`previous-resource-day`、
`stats-date-unaligned` 等状态，且只允许落后 1—7 个自然日的资源后移一次。

这次统计日和触板事件日均为 2026-07-31，所以昨日封单取
`prev_seal_amount_10k`。历史封单有时为负；保留原始有符号值，但只有
大于零时才计算封昨比，避免把状态编码口径当成正委托金额。

## 四路交叉验证与新增指标

对全部 231 只触板股重新运行 `update_tdx_limit_quality.py`：

- `0x0547`：101 只封板、130 只炸板；
- 原生日统计：`ztjs2=101`、`ztjs3=130`；
- `0x054B`：封单额榜连续封板前缀 101 只；
- `tdxstat2.cfg`：101 只有当日正封单，按万元两位小数还原后全部在
  100 元容差内匹配五档买一金额。

新增指标为：

```text
封流比 = 当前封单 / (自由流通股数 × 当前价) × 100%
封昨比 = 当前封单 / 昨日正封单
封单变化 = (封昨比 - 1) × 100%
封单衰减 = (1 - 封昨比) × 100%
```

封单衰减为正表示减弱、为负表示增强；炸板且盘口存在时当前封单按 0，
因此昨日曾正封单的炸板股可显示 100% 衰减。本次 231 只均关联到统计行，
17 只存在正的昨日封单。封流比前三为传智教育 6.82%、爱丽家居 5.84%、
中岩大地 5.51%；封昨比前三为泛微网络 5.77、普联软件 4.89、传智教育
1.13。以上均为协议验证样本，不构成投资建议。
