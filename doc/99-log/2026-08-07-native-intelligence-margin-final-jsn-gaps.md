# 情报专题、分类两融与最后一批已下载 JSN 缺口

## 目标

继续按通达信客户端真实功能推进，不扩展 L2，也不把工作重心转成纯网页装修。
本轮处理覆盖审计中最后 16 个“文件已经下载但仍只有通用入口”的模板，并将
对应的主从关系、单位、图表投影和网页入口固定到纯 C++ 工具。

## 关键语义

1. `ztxx` 与 `xwlb` 的 `title` 可能包含 `TXT:` 后缀和 HTML。C++ 同时保留
   原始行、拆出标题、转为纯文本正文并提取原文 URL；Svelte 不使用原始 HTML
   渲染，避免把上游标签直接注入页面。
2. 大盘异动复现客户端公式：当日涨跌幅为
   `(收盘-昨收)*100/昨收`，后一周涨跌幅为 `(后一周收盘-当日收盘)*100/当日收盘`；
   两市成交量和成交额分别由沪深字段相加。
3. `rzrq6/7/8` 已经是元；`rzrq5` 的融资余额/两融差额是亿元，融券余额是
   千万元，分别乘 `1e8` 和 `1e7` 后输出标准元字段。
4. `hsgtcg2.jme` 为万元，乘 `1e4` 后与 `hsgtcg1` 的元字段逐日对账。
   `ggthy1.drjlr` 为亿元，乘 `1e8` 后输出元。
5. `sjqd` 动态成员与主表 `$S_ZQDM` 同时保留并返回 `exact_match`、差集与数量；
   事件和 ETF 两融规范记录补齐 `raw`，保证契约能追溯到原字段。
6. `gdzjc1` 是图表投影而不是新的增减持主表。当前主表 37 个月、投影 36 个月；
   重叠月份匹配 32、差异 4。差异集中在近期公司数，符合两资源刷新时点不同的
   特征，服务只报告对账，不伪造完全一致。

## 网页接入

- “市场情报”新增专题追踪、专题文章下钻、新闻联播、大盘异动复盘和事件动态
  成员展开；正文只显示清洗后的纯文本。
- “融资融券”新增行业、概念、风格分类列表，点击分类可读取完整历史。
- “沪深港通”补齐此前 C++ 已有但网页未展示的当前持仓、七类历史增减仓、
  北向分类、指定日活跃股，以及南向行业成员下钻。
- “股权变动/市场统计”新增增减持公司数图表投影和主表对账提示。

## 验收结果

- JSN 覆盖：`332/616` 类型化、`284` 个通用入口；
- 下载对账：340 个本地文件全部匹配，解析错误 0，已下载非空模板通用独占 0；
- C++：65/65 测试通过；
- Svelte：`svelte-check` 0 错误/0 警告，生产构建成功；
- 正式 HTTP 契约：90/90 通过，证据位于
  `output/probes/api-contracts-after-intelligence-margin-current.json`；
- 覆盖证据：`output/probes/jsn-variants-after-final-gaps-current.json`；
- 正式服务 PID `29524`，可执行文件 SHA-256
  `6663D5E6B785280ACEA0044E5E2953D17C1B408041820898858CD1B4F42849BC`。

## 后续边界

当前剩余 284 个通用模板并不代表有 284 个可立即实现的非空功能：它们没有本地
非空下载样本，部分是未触发的动态键，部分可能是当前零长度/停用分支。下一步
应继续从客户端页面或新增下载样本中发现真实键和值，再按“非空样本、明确字段、
能形成主从关系”的顺序固定；不应仅为提高覆盖数字批量猜测 schema。
