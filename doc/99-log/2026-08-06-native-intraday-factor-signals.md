# 盘中机会与六类因子信号纯 C++ 固定化

`gp_gz_dxjh.xml` 同时定义了普通 TQLEX JSON 的 `200661` 两类盘中机会和
`200662` 六类因子信号。它们此前只能通过通用云查询入口按 flag 调试，本轮
并入已有 `market technical-signals` 和固定
`/api/v1/market/technical-signals`，业务视图由 24 增至 32。

## 固定视图

| view | ReqId/flag | 客户端名称 | 客户端语义 |
|---|---|---|---|
| `intraday-opportunity` | 200661/1 | 个股机会 | 分时级计算，安全分不低于 60 |
| `t0-opportunity` | 200661/2 | T+0机会 | 分时级计算，标的支持 T+0 |
| `accumulation-surge` | 200662/1 | 积突 | 量价连续上扬创新高；再次满足为“突” |
| `new-high-low-120` | 200662/2 | 高低 | 创 120 日新高或新低 |
| `ma120-cross` | 200662/3 | 上下 | 上穿或跌破 120 日均线 |
| `ma-break-reclaim` | 200662/4 | 破立 | 一阴破或一阳穿 5/10/20 日均线 |
| `pullback-rally` | 200662/5 | 踩拉 | 缩量回踩 5 日线或放量上涨 |
| `ma-support-pressure` | 200662/6 | 托压 | 5/10/20 日均线向上/向下形成封闭三角形 |

八个视图都固定使用客户端 `sortType=3、desc=1、Page=0、PageSize=500`。
`200661` 每 10 秒、`200662` 每 30 秒增量刷新。个股机会复现
`safety>=60`，六类因子复现 `safetyvalue>=60`；T+0 页不应用安全分过滤，
当前全体 `safety=-1` 明确规范化为“不适用”而不是负分。

## 字段和行情边界

`200662` 上游只有 `time/code/name/market/falg/value/safetyvalue` 七列。
现价、实时涨幅、行业和市值是客户端行情系统列，不属于 TQLEX 响应；接口
因此稳定返回入选时间、入选价、信号字符/解释和安全分。`200661` 返回
`code/name/market/rxyz/rxsj/rxhzf/safety`，其中入选后涨幅是上游确定字段。

`--quotes` 或 API `quotes=1` 可额外批量调用公开 L1 `0x054C`，填充
`current_quote`，并在存在入选价时本地计算入选后涨幅。行情增强失败只生成
警告，不使源信号失效；默认不请求行情，避免单票 32 视图反查重复拉取全榜。

## 真实复验

2026-08-06 盘中复验中，六类因子过滤后分别返回 55、20、309、51、80、
346 行；集合随 10/30 秒刷新继续变化。积突中 6 只股票同时保留先“积”后
“突”两条事件，因此快照身份使用“证券＋信号＋入选时间”，不能只按证券去重。
连续两次 59 行积突快照得到 0 新增、0 消失、0 变化，证明同股双事件可稳定
比较。

个股机会当前上游达到客户端单页上限 500 行，安全分过滤 45 行后返回 455；
这只证明当前页，不宣称全市场总量。T+0 返回 30 行，全部为可转债且安全值
为 `-1`；可选行情增强一次取得 30/30 快照，同时保留上游入选后涨幅。

`SZ300204 舒泰神` 的 32 视图反查第二次完成 32/32，命中积突信号；首轮曾
因 `rps-stock` 连续返回 `RpcID=-1` 而正确标成 partial，重试恢复后为
`live/complete`。正式 API 也出现一次短暂 partial、下一次 32/32 恢复；据此
将同链瞬时故障重试从过密的三次调整为最多五次指数退避，总等待上限 3.75 秒，
仍不会无限阻塞或把持续故障伪装成未命中。原始与规范化证据位于
`output/probes/tqlex-200661-*`、`tqlex-200662-*`、
`technical-signals-<view>.json` 和单票 32 视图探针。
