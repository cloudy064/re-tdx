# 公开 JSN 镜像刷新与类型化覆盖复核

## 目标

在不凭 CFG 名称猜测新接口的前提下，复核本地 601 个公开 JSN 样本是否已经陈旧、
远端是否出现新字段，以及尚未类型化的静态模板是否真的可下载。探测和下载均使用
统一 C++ 工具，没有 Python 运行时或转发层。

## 远端元数据与刷新

以刷新前 SHA-256 基线
`output/probes/jsn-pre-refresh-baseline-20260812.json` 为独立参照，对 601 个资源分
7 批读取远端长度和 MD5：601/601 可用，合计 225,092,917 字节。与本地镜像相比，
487 个远端内容已变化，114 个一致。

其中 13 个超过 2,000,000 字节的债券/行业全量投影合计 168,758,783 字节，属于
此前已经证明可由类型化主表重复得到的超大冗余视图，本轮不重复覆盖。其余 474 个
变化资源分 5 批原子下载，55,383,882 字节全部成功；下载中途即使进程超时也不会
留下半文件。

元数据和下载报告为：

- `output/probes/jsn-refresh-probe-01-20260812.json` 至 `07`
- `output/probes/jsn-refresh-download-01-20260812.json` 至 `05`
- `output/tdx-jsn-discovery-refresh-20260812.json`

## 刷新后字段审计

相对刷新前基线，当前仍为 601 个文件，其中 474 个内容变化、127 个保持原本内容；
没有文件增删。最重要的是结构结果没有变化：

- 601/601 可识别，601/601 命中类型化命令；
- `generic-only=0`，解析错误为 0；
- 新增字段 0，删除字段 0；
- 517 个样本含证券关系键。

因此本轮变化只是正常的行内容滚动，没有形成新的类型化命令或 API 候选。

## 未下载模板复核

`recon jsn-variants` 当前合并 622 个资源模板，其中 588 个已有类型化命令，34 个
仅因没有下载样本而显示为 `generic-only`。这 34 个全部是无占位符的静态路径，已
逐一直接探测：0 个可用、34 个缺失、总长度 0。报告为：

- `output/tdx-jsn-variants-refresh-gaps-20260812.json`
- `output/tdx-jsn-static-gap-probe-20260812.json`

动态候选生成器仍能组合出大量具体证券路径，但它们是从主表行做的笛卡尔展开，
不能视为服务端存在性证据，也不应无边界批量探测。

## 结论

截至本次远端快照，公开 JSN 队列没有未实现的非空静态资源，也没有新字段。后续只
在 CFG/客户端页面新增模板、现有资源出现结构变化，或 34 个缺失静态路径变为非空
时重新打开实现队列；定期刷新行内容不需要改 C++ 解析器或运行全套测试。
