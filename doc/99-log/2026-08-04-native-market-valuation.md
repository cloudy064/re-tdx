# 市场指数估值 JSN 链纯 C++ 迁移

> 日期：2026-08-04  
> 范围：通达信指数估值主表、动态 PE/PB 历史、关联基金、固定 API 与网页入口。

## 客户端证据

`T0002/cloud_cfg` 中四份列表配置给出了完整业务含义和动态资源单元：

| 配置 | 资源 | 语义 |
|---|---|---|
| `func_zsgz101.cfg` | `list/func_zsgz101_1.jsn` | 指数、当前 PE/PB、历史百分位、ROE、股息率和区间收益 |
| `func_zsgz102.cfg` | `zsgz1/<指数ID>.jsn` | 关联指数基金及净值、溢价率、份额 |
| `func_zsgz104.cfg` | `zsgz3/<指数ID>.jsn` | 逐交易日 PE 和 PE 历史百分位 |
| `func_zsgz105.cfg` | `zsgz4/<指数ID>.jsn` | 逐交易日 PB 和 PB 历史百分位 |

动态路径使用主表隐藏字段 `$ZQDM`，不是市场号与证券代码的拼接。
`zsgz1/000001.jsn`、`zsgz3/000001.jsn` 和 `zsgz4/000001.jsn` 均由
7709 `709/1721` 真实请求确认；`1000001`、`1_000001` 等猜测路径不存在。

## 纯 C++ 实现

- 新增 `market valuation` 子命令，不依赖 Python 或预下载文件；
- 主表规范化为指数证券、当前指标、5/10/20/30 日收益和详情 ID；
- 一条 7709 会话批量取得基金、PE、PB 三张详情表；
- PE/PB 按日期合并，缺失值保留为空，支持起止日期及最近 N 条限制；
- 服务进程分别缓存主表和指数详情，固定 API 为
  `/api/v1/market/valuation`；
- Svelte 新增“市场估值”页，支持指数与 PE/PB 切换、完整历史缩放和关联
  ETF 查看。

协议级测试覆盖主表字段、中文估值标签、基金字段及 PE/PB 非对齐日期合并。

## 真实验收

2026-08-04 查询 `SH000001 上证指数`：

| 项目 | 结果 |
|---|---:|
| 估值主表指数 | 11 |
| 关联指数基金 | 6 |
| PE 历史 | 3,058 |
| PB 历史 | 3,058 |
| 合并历史范围 | 2014-01-03—2026-08-03 |
| CLI 冷进程 | 约 863 ms |
| 临时 API 冷请求 | 约 470 ms |
| 同进程缓存请求 | 约 129 ms |

缓存请求的 `master_refreshed` 与 `detail_refreshed` 均为 `false`，确认没有
重复访问上游。网页生产构建和 C++ 自检通过，注册功能数由 24 增至 25。

## 边界

- 这是指数市场估值，不是个股财务估值，也不是之前 PBRPC 工作流中的
  “指数相对估值比”；两条链的口径与覆盖范围不同。
- 数据日期和覆盖指数由通达信主表决定；工具不外推不存在的指数。
- 关联基金名称优先使用本地证券名称表，未解析名称仍保留市场与代码。
