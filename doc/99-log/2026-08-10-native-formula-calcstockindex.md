# TCalc CALCSTOCKINDEX 跨证券嵌套指标闭环

## 原生调用语义

`CALCSTOCKINDEX(证券代码, 指标名称, 输出序号)` 对应 TCalc opcode 1109、处理
函数 `sub_10041600`。反编译确认三个参数都取末柱：前两个通过宿主字符串句柄还原，
第三个是从 1 开始的指标输出序号。指标名称在技术指标目录中匹配，输出名称直接按
目录记录的原始顺序选择，不能按 JSON 对象键排序。

原处理函数按当前周期为目标证券追加约 3,000 根预热数据，执行所选指标，再把目标
结果映射到调用方的日期/时间柱。目标柱缺失时只允许紧邻一个调用方柱继承前值；继承
值不会继续触发下一次继承。原 DLL 会拒绝直接自引用，本实现进一步用调用栈覆盖间接
循环，并把嵌套深度限制为四层。

## C++ 实现与拆分

- `formula_catalog_internal.cpp` 统一选择技术指标、检查一基输出序号和执行策略；
- `formula_nested.cpp` 负责 SH/SZ/BJ 证券解析、同周期 K 线抓取、嵌套上下文、结果
  缓存、时间戳对齐、单缺口继承、深度与循环保护；
- 分析器只接受两个静态字符串和 `1..64` 的常量输出序号，动态参数明确列入
  `context_bindings_unavailable`；
- 求值器消费 `CALCSTOCKINDEX#证券#指标#序号` 时间序列，API 返回解析目标、输出名、
  目标柱数、精确匹配数和单缺口继承数等审计元数据；
- `INSORT/INSUM` 同步改用公共目录选择器，删除原先复制的选择和校验代码。

## 增量验证

受影响的 `tdx-formula-engine-tests` 与 `tdx-recon-contract-tests` 均通过，没有运行
全量 CTest。候选服务健康、能力清单、真实执行和动态参数拒绝四项聚焦接口通过；
动态证券参数得到 HTTP 400。真实 POST 在平安银行 120 根日线上执行
`CALCSTOCKINDEX('SH000001','MACD',1)`，目标自动解析为 `sh:000001`、`MACD.DIF`，
下载 3,200 根目标日线，120 根调用方柱全部精确匹配，单缺口继承为 0，最新值为
`-20.89670065154087`。

能力清单由 261 增至 262 个支持函数，87 个自动符号不变。候选构建 SHA-256 为
`83E8234069749DC872A29B00D8975A6256D7F28F29DDF10553DFD1C81A06E26B`；本批尚未
替换 8765 正式服务，准备与当前未发布的 RAND/评分批次合并执行一次阶段发布回归。
