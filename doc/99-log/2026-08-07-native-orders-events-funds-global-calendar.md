## 结论

本轮继续限定在公开、非 Level2 数据面，把 25 张新验证的 JSN 表从通用下载资源
提升为纯 C++ 业务接口，并接入正式服务和 Svelte 页面。新增三个独立命令：

```text
tdx-tool market corporate-orders --input-dir output/tdx-jsn --view all
tdx-tool market event-impact --input-dir output/tdx-jsn --benchmark all
tdx-tool market global-performance --input-dir output/tdx-jsn --view all
```

对应固定 API 为：

```text
GET /api/v1/market/corporate-orders
GET /api/v1/market/event-impact
```

工作台，可从股票反查招投标、中标和重大合同。场内基金、日历和机构分析继续沿用
已有接口扩展视图，没有增加重复服务。

## 语义与边界

- 公司订单金额、收入占比和合同字段均按客户端 CFG 列定义类型化。4,694 条具备
  计算条件的订单逐行复算，公式不一致为 0；没有金额或收入基数时保留空值。
- 事件影响保留事件前后指数收盘和源百分比窗口；缺失结束日期或收益不推断，三个
  指数族也不混合成交量等不可比单位。
- 全球表现使用表内隐藏参考收盘列本地计算 5/20/60 日、本月和年内收益；指数
  名称优先合并 7727 证券目录。海外目录仍有 26 个名称无法解析，代码和原始行
  完整保留，不臆造名称。
- 基金规模、份额、净值、参考标的、费用、折溢价、到期日及现金可用/可取日均按
  各表自身口径保存；不同市场、不同币种的成交额不做无依据汇总。
- 全部能力只使用公开静态表和公开 L1；不尝试绕过 Level2 订阅或授权。

## 服务阻塞修复

真实浏览器回归发现 Chromium 会对 localhost 建立推测性连接，但可能暂时不发送
HTTP 请求。内嵌服务按连接串行处理，旧实现对 `recv` 没有超时，因此一个空闲预连
接就能阻塞后续所有 API，看起来像“页面无数据”。服务现为已接受连接设置 2 秒
读取超时；超时连接会释放，正常健康检查在浏览器连接存在时仍可约 100 ms 返回。
这不是数据源或 JSN 解析问题。
