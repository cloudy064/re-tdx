## 客户端语义证据

`func_kkzss101.cfg` 对应“可转债发行 → 已发可转债”。原始字段同时给出债券、
正股、申购日期/代码/上限、转股起始日、正股收盘价、转股价、债券收盘价、发行
总数、中签日期/中签率和上市日期。页面显示列的两项派生公式为：

- 转股价值：`正股收盘价 × 100 / 转股价`；
- 转股溢价率：`(债券收盘价 - 转股价值) × 100 / 转股价值`。

其中申购上限的原始单位是万元，发行总数是亿元，中签率是百分比点。接口分别以
`subscription_limit_10k_yuan`、`issue_size_100m_yuan` 和
`lottery_rate_pct` 保留，未把三个量纲混为普通数值。

`PGMZ.sp` 则证明 QXFA 107/108/109 是相互独立的配股生命周期页面：107 为
“配股实施”，108 为“配股审议中”，109 为“配股进度异常”。实施表下发实际
配股代码、比例、价格、数量、募资及缴款/登记/除权日期；审议与异常表下发进度、
方案比例、计划数量、计划募资及发行详情。因此同一证券跨阶段或重复事件不能按
证券代码粗暴去重。

## 纯 C++ 与网页能力

`market convertible-bonds --view subscriptions` 新增独立类型化结果、来源健康、
市场/代码/文本过滤和按申购日、上市日、发行规模、溢价率、中签率排序。每条记录
带稳定 `event_id`、原始行和正股关联；其他可转债视图也保留空
`subscriptions` 数组，使 API schema 稳定。

`market futures-issuance --section rights` 将三阶段统一为
`implemented/deliberating/abnormal`，同时保留中文状态、进度日期、金额语义
`actual/planned` 和各类业务日期。摘要分别聚合实际/计划金额、股数、阶段和状态，
市场、代码与文本过滤同样可用。

Svelte 数据中心增加“发行申购”和“配股募资”视图；个股工作台的关联转债与
定向增发面板也分别加载单票申购、配股事件。网页只消费正式 C++ API，没有加入
Python 转发或浏览器侧业务复算。
