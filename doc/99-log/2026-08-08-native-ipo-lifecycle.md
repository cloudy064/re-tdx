> 日期：2026-08-08。范围：公开非 L2 JSN、纯 C++ `market calendar`、固定 API 与 Svelte 数据中心。

## 新发现

`recon jsn-discovery` 首先在 504 个本地资源中找到唯一的通用入口缺口
`list/func_zdgz_kcbsq103_1.jsn`。客户端 GBK CFG 将其定义为新股申购表，
字段覆盖申购日、发行价、中签率、有效申购金额、发行市盈率、上市至今涨幅、
报告期、每股收益/净资产/现金流、净资产收益率、发行前总股本、拟发行股数、
发行后占比、拟融资金额和公司简介。

文件大小为 693,486 字节、MD5 为 `7bb56dd10c3d84b08e05a42cb33f49a0`；
限量下载后解析出 514 家 IPO 审核企业、19 个字段和零解析错误。

## 纯 C++ 能力

`market calendar` 新增两个视图：

- `--view ipo-review`：514 家企业的公告/受理日期、审核状态、板块、行业、
  保荐人、招股书、财务指标、拟发行结构、拟融资金额与公司简介；
- `--view ipo-subscriptions`：34 家待申购或近期申购企业的证券身份、申购日、
  发行价、中签率、有效申购金额、发行估值、上市涨幅和同口径财务/发行结构。

审核状态当前分布为：已问询 335、终止 59、中止 36、提交注册 34、注册生效
22、上会通过 13、终止（撤回）8、已受理 4、暂缓审议 2、终止注册 1。
板块分布为北交所 275、创业板 101、科创板 84、主板 54。

申购表 34 行覆盖四个板块；32 行已有发行价，27 行已有中签率和有效申购金额，
23 行已有上市至今涨幅。拟融资金额和有效申购金额保持客户端原始“元”，中签率
与发行后占比保持原始百分数点。499 条审核记录和全部 34 条申购记录可用
`拟发行股数 / (发行前总股本 + 拟发行股数) × 100` 复算发行后占比。

审核主表没有证券市场/代码，只含内部企业 ID。工具仅用唯一证券名称和当前申购表
的精确企业名建立关联；当前可证明关联为 1 条，其余保持 `security=null`，不做
模糊名称猜配。申购表自身的 `$SC1/$ZQDM1` 则直接形成沪深京证券身份。

Svelte 财经日历增加“IPO审核”和“新股申购”入口，仍复用类型化 API；这只是把
新 TDX 能力暴露出来，没有引入独立前端数据逻辑。
