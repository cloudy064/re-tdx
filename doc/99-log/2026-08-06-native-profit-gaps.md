# 利润断层纯 C++ 固定化

## 结论

`T0002/cloud_cfg/gp_gz_lrdc.xml` 的利润断层页面使用普通 JSON TQLEX：

- Entry：`HQServ.hq_nlp_caps`；
- ReqId：`500601`；
- 模块：`mod_caps.dll`；
- 固定请求：`DataDate=0`、`SetCode=3`；
- 服务字段：市场、代码、名称、断层日期、断层涨幅、披露类型编码和安全分。

新增纯 C++ `market profit-gaps` 和固定只读
`/api/v1/market/profit-gaps`。`Bglx` 的 34 个客户端枚举被类型化为一季度、
半年度、三季度或年度，以及预告、快报或正式报告；每条事件使用
“市场代码+日期+披露类型”作为稳定身份。接口支持文本、市场和六位代码过滤，
并使用 5 分钟内存缓存。

## 客户端过滤与字段边界

XML 在 datasource 后使用 `Aqf >= 60` 的二级过滤，它不是服务器请求条件。
2026-08-06 实测上游返回 69 条，默认复现客户端后为 65 条，4 条低安全分事件
被排除；`--minimum-safety 0` 可显式取得完整 69 条用于审计。65 条全部属于
半年度披露，其中预告 52、快报 5、正式报告 8，事件日期覆盖 2026-06-26 至
2026-08-06。

原页面的现价、涨跌幅、成交量额、流通/总市值和行业均声明为宿主 `syscol`，
不在 `500601` 的七个返回字段内。固定接口没有以空值或相似来源伪造这些列。
响应也明确说明利润断层是服务端模型事件，并不等同于投资建议。

## 真实样本

华海药业 `SH600521` 当前命中一条 2026-07-06 半年度预告事件，断层涨幅
7.59%，安全分 79。纯 C++ 单票过滤返回 1 条；默认全表返回 65 条，取消安全
分过滤返回 69 条。探针保存在：

- `output/probes/tqlex-500601-current.json`；
- `output/probes/profit-gaps-current.json`；
- `output/probes/profit-gaps-unfiltered-current.json`；
- `output/probes/profit-gaps-sh600521-current.json`。

新增单元测试覆盖市场/证券身份、名称回填、日期、断层涨幅和披露类型映射。
