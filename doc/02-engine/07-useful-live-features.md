# 可产品化的直连行情功能

> 目标不是罗列通达信菜单，而是筛选能与现有“板块树—成分股—分钟线”
> 数据直接组合、适合做成自用工具的功能。以下结果均在 2026-07-31 使用
> 普通 Python 进程直连 `7709/TCP` 主站验证，不依赖 TdxW 进程或本地 DLL。
> 文中的即时行情仅用于协议验证，不构成投资建议。

## 关键闭环：板块广度可以独立重算

银行板块 `880471` 有 42 个直接成分股。一次批量快照取得全部 42 只股票
后，按现价与昨收计算得到：

```text
上涨 0 / 下跌 42 / 平盘 0
```

同一分钟的银行指数 K 线尾部字段为：

```text
up_count=0 / down_count=42
```

两条独立数据链完全一致。这同时确认了 `.lc1` 末尾两个 `uint16` 的业务
含义，也说明工具可以：

- 使用板块指数自带字段快速展示广度；
- 使用成分股快照重新计算并校验；
- 找出板块上涨/下跌主要贡献股；
- 发现板块目录或行情数据发生错配。

## 推荐产品顺序

### P0：板块雷达 / 行业热力图

收益最高，且实现成本最低。现有树状板块页面增加一份行情快照即可：

- 110 个通达信叶子行业的涨跌幅、振幅、成交额和当前指数；
- 涨幅、成交额、攻击幅度、回撤等排序；
- 红绿热力图和一级/二级/三级行业聚合；
- 点击行业后显示指数分时和现有 1 分钟 K 线。

当前 110 个叶子行业已做到 `110/110` 返回，只需要两个不超过 80 个代码
的批次。

### P0：板块详情与成分股联动

把现有成分关系和批量快照拼接：

- 板块实时上涨/下跌/平盘家数；
- 成分股涨幅、成交额、振幅、现价排行；
- 领涨前五、拖累前五；
- 指数自带广度与成分股重算广度的差异告警；
- 点击成分股反查其全部行业、概念和风格板块。

银行 42 只成分股已验证可以一次请求取全。

### P1：盘前集合竞价面板

在 09:15—09:25 展示：

- 虚拟开盘价轨迹；
- 匹配量和未匹配量；
- 未匹配方向翻转；
- 09:25 最终竞价涨幅、金额；
- 板块内竞价最强和最弱成分股。

竞价命令当前按单代码查询。批量扫描时应限制并发和刷新频率，不宜对所有
证券高频轮询。

### 已完成：开盘抢筹公式与开/收盘竞价逐点

`tdx_auction_series.py` 已实现 `0x056A` 的 28 字节请求与 16 字节定长记录。
当前主站的准确行为为：

- `selector=0` 只返回约 09:15—09:25 的开盘竞价；
- 任意非零 selector 返回开盘竞价，再拼接约 14:57—15:00 的收盘竞价；
- `start_raw/limit` 对合并后的点序列分页；
- 深市活跃股票常见开盘 68 点、收盘 20 点，采样约每 9 秒一次；
- 北交所采样间隔和点数不同，不能假设固定 68/20；
- 未匹配 `int32` 正数为买方未匹配、负数为卖方未匹配，已用涨停买单和
  跌停卖单样本交叉验证。

开盘段最后一个深市样本通常是 `09:24:57`，并非 09:25 正式成交。
`0x054B/0x010A` 的“开盘抢筹”公式已经恢复：

```text
开盘抢筹 = (正式开盘价 / 0x056A 最后一个开盘样本价 - 1) × 100%
```

对抢筹最高和最低各 30 只、共 60 只证券验证，全部在 0.02 个百分点误差
内匹配原生值。榜首陇神戎发的末样本价为 11.44 元、正式开盘价 13.03 元，
还原值 13.8986%，原生值 13.90%。

`update_tdx_auction_quality.py` 现已把 `0x0FC6` 成交明细接入。抢筹最高 30
只的 09:25 成交价与分类行情开盘价 `30/30` 一致，成交量与 `tdxstat2`
`30/30` 在 1 手内一致；精确成交额与压缩后的分类/统计金额 `30/30` 在
1,000 元内一致。收盘段常停在 `14:59:51` 左右，工具使用 15:00
`status=2` 集中撮合记录闭合正式收盘价、量、额：最高 30 和最低 30 的
正式收盘价均 `30/30` 与分类行情一致。

最低榜同时暴露了一个重要边界：两只北交所证券当天没有 09:25 成交，
首笔交易在 09:30；其 `0x054B/tdxstat2` 开盘量额仍等于 09:24:57 虚拟
匹配值。工具因此只在成交明细确有 09:25 记录时声明“正式开盘竞价量额”，
否则输出 `no-0925-trade`，并把其余字段称为“竞价参考量额”。

### P1：多周期板块强弱

在同一页面加入 5/15/60 分钟及日/周/月线：

- 相对沪深基准的区间强弱；
- 当日高点回撤和低点反弹；

### P1：成分股统计与短线标签

`zhb.zip` 中的 `tdxstat.cfg/tdxstat2.cfg` 可以通过 `0x06B9` 从主站更新，
当前已确认的字段包括：

- 60 日 Beta、滚动市盈率和流通股本；
- 当日、昨日、前日成交额；
- 当日和昨日 09:25 开盘量、开盘金额；
- 涨停统计窗口、窗口内涨停次数、连板天数和年内涨停天数。

同一压缩包还包含 `tipinfo.dat`。其第 18/19、20/21、22 字段分别是带方向的
北向大幅增减仓日期、回购方案日期/比例和股权激励方案日期；这三组字段会被
TdxW 写入 `0xA3` 宿主记录，并由 TCalc 映射到 `FINANCE(88..91)`。2026-08-05
在线包有 5,615 条 tipinfo 记录，其中北向日期/方向非空为 0，回购日期 2,294 条、
激励日期 1,445 条；因此北向公式当前返回 0 是上游数据状态，不是解析失败。

另一个与北向相关但语义不同的本地资源是 `hq_cache/spblock.dat`。宿主 type 105
从 `#沪港通SH`、`#深港通SZ` 两节的成员并集生成 `FINANCE(48)`，从
`#融资融券` 生成 `FINANCE(52)`；它们表示当前是否为对应标的，不是资金值或
事件日期。原生公式上下文已按这一精确语义接入，并按文件时间自动刷新缓存。

`DYNAINFO(28/29)` 则不是板块或资格数据，而是 TdxW 的即时买卖笼子价。
TCalc 请求宿主 type 121、selector 198；TdxW 先取卖一/买一，并按另一侧、现价、
昨收回退，普通证券使用 2% 约束、北交所使用 5% 约束，股票还叠加至少 10 个
价位，最后受涨跌停价截断。原生上下文使用一次 `0x0547` 五档请求同时提供盘口
和普通快照字段，避免重复网络往返；系统 `FSCAGE` 公式已经可以直接运行。

它适合为板块成分表增加估值、流通市值、竞价昨比和“几天几板”等标签。
统计资源必须检查主导日期和覆盖率，不能把旧文件与今日行情直接错位
拼接。本机旧缓存主导日期为 2026-07-29；2026-08-01 从主站重新下载后
主导日期为 2026-07-31，说明在线刷新确有必要。若统计日等于目标交易日，
昨日值取 `prev_*`；若统计日恰为前一交易日，昨日值才取当行字段。

### 已完成：成交回放与竞价闭合

`tdx_trades.py` 已实现 `0x0FC5/0x0FC6`：

- 指定分钟的成交明细回放；
- 买卖方向、成交量和委托笔数统计；
- 09:25 开盘、15:00 收盘以及深市 15:05—15:30 盘后定价分段；
- 股票百分位、ETF/债券千分位价格刻度。

协议的 `start=0` 从最新记录块开始向历史回溯，但每个块内部仍按时间正序；
服务器即使请求 2,000 条也最多返回 1,800 条，所以必须按实际返回数推进，
并在空页而不是短页终止。输出已统一改为时间正序。单条记录包含分钟、价格
差分、量、成交笔数、状态和尾字段；时间精度只有分钟，仍是公开 L1 聚合
成交明细，不是完整 Level2 秒级逐笔委托。

### P2：持续刷新/推送

`0x0547` 已具备增量刷新基础，但持续实时页面需要一个常驻 Python 进程或
本地服务。浏览器直接双击打开的 HTML 不能建立任意 TCP socket，因此：

- “更新后双击查看”继续使用 Python 下载后嵌入 HTML；
- 真正实时刷新需要本地 WebSocket/HTTP 服务，或定期重新生成页面。

这与当前优先保持单文件 HTML 的目标冲突，暂不作为第一阶段。

## 已完成：一键市场快照

2026-07-31 已实现“一键市场快照”更新器，数据流为：

```text
本地板块/成分文件
        +
7709 板块指数批量快照
        +
7709 全部唯一成分股批量快照
        ↓
预计算板块排行、广度、领涨/拖累
        ↓
gzip 嵌入单文件 tdx-market.html
```

实现文件：

- `doc/90-scripts/tdx_market_snapshot.py`：`0x054C` 协议与主站切换；
- `doc/90-scripts/tdx_market_depth.py`：`0x0547` 五档与当前买一/卖一金额；
- `doc/90-scripts/tdx_category_quotes.py`：`0x054B` 服务端分类与完整封板榜；
- `doc/90-scripts/tdx_stats.py`：`0x06B9` 在线/本地统计资源；
- `doc/90-scripts/update_tdx_market.py`：数据拼接、指标预计算和原子输出；
- `doc/90-scripts/build_tdx_blocks_html.py`：图谱/行情两种数据兼容的单文件
  页面。

真实全量验证使用 5,972 只唯一成分证券和 1,039 个可定位板块/指数，共
7,011 个唯一请求代码、88 个批次；单一主站约 8 秒完成，收到 7,003 个
请求标识匹配的快照，其中可计算涨跌的行情覆盖 5,949 只成分证券和 1,035

标识过滤，未把行情错误关联给请求代码；停牌或当前价为 0 的记录也不纳入
广度、领涨和拖累计算。生成的 HTML 约 907 KiB，其中 gzip 数据约
638 KiB。

页面现在支持：

- 行业树和平铺导航；
- 按板块指数涨幅或成分平均涨幅的行情排行；
- 板块上涨/下跌/平盘家数、平均涨幅、成交额；
- 领涨、拖累证券；
- 成分股按涨幅或成交额排序；
- 个股行情及所属板块反查；
- 带行情列的当前板块 CSV 导出。

运行：

```powershell
python doc/90-scripts/update_tdx_market.py --download
```

它满足：

- 一个 Python 命令更新；
- 一个 HTML 双击打开；
